Linked Lists

A linked list is a linear data structure made up of nodes. Each node stores data and one or more links that connect it to other nodes.

Learning objectives: Understand nodes and pointers, identify types of linked lists, perform basic operations and write a simple linked list program in C++.

1. Definition

A linked list is a dynamic linear data structure in which elements are stored in separate nodes connected using links or pointers.

Unlike an array, the nodes do not have to occupy consecutive memory locations.

HEAD
  |
  v
[10 | next] → [20 | next] → [30 | NULL]

Each box represents a node. The final node points to NULL, indicating that there is no next node in a normal singly linked list.

2. What Is a Node?

A node is an individual unit of a linked list. A node in a singly linked list contains:

  • Data field: Stores the value.
  • Link field: Stores a pointer to the next node.
struct Node {
    int data;
    Node* next;
};

data stores an integer and next points to another node.

Head: A pointer to the first node. If the list is empty, head is NULL or nullptr.

3. Types of Linked Lists

A. Singly Linked List

Each node points to the next node. Traversal normally proceeds in one direction.

HEAD → [10] → [20] → [30] → NULL

Application: A simple sequence of records.

B. Doubly Linked List

Each node has links to both the previous and next nodes.

NULL ← [10] ⇄ [20] ⇄ [30] → NULL

Application: Navigating both forward and backward through items.

C. Circular Singly Linked List

The last node points back to the first node instead of pointing to NULL.

HEAD → [10] → [20] → [30]
         ↑              |
         └──────────────┘

Application: Repeating cycles of tasks.

D. Circular Doubly Linked List

Each node has previous and next links, and the first and last nodes connect to one another in both directions.

Application: Circular navigation through items in either direction.

4. Creating a Linked List in C++

The following program creates three nodes and connects them.

#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;
};

int main() {
    Node* first = new Node{10, nullptr};
    Node* second = new Node{20, nullptr};
    Node* third = new Node{30, nullptr};

    first->next = second;
    second->next = third;

    Node* head = first;
    Node* current = head;

    while (current != nullptr) {
        cout << current->data << " ";
        current = current->next;
    }

    delete third;
    delete second;
    delete first;

    return 0;
}

Output:

10 20 30

How it works:

  1. Three nodes are created dynamically.
  2. Each node stores a value and a pointer.
  3. The next pointers connect the nodes.
  4. head points to the first node.
  5. The loop visits each node until it reaches nullptr.
  6. The dynamically allocated nodes are deleted to release their memory.

5. Traversal

Traversal means visiting each node, usually from the head to the end of the list.

Node* current = head;

while (current != nullptr) {
    cout << current->data << " ";
    current = current->next;
}

Initially, current points to the first node. Each step moves to the next node. The loop stops when current becomes nullptr.

Time complexity: O(n), because the algorithm may visit all n nodes.

6. Insertion

Insertion means adding a new node to a linked list.

A. Insertion at the Beginning

  1. Create a new node.
  2. Make its next pointer point to the current head.
  3. Update head to point to the new node.
Node* newNode = new Node{5, head};
head = newNode;

This inserts the value 5 at the beginning. It takes O(1) time when the head pointer is available.

B. Insertion at the End

Create a new node whose next pointer is nullptr. Traverse to the last node and link its next pointer to the new node. With only a head pointer, traversal takes O(n); with a maintained tail pointer, insertion can be O(1).

C. Insertion in the Middle

Find the node after which the new node should be inserted. Link the new node to the following node, then link the previous node to the new node. Finding the position may take O(n).

7. Deletion

Deletion means removing a node from the list and releasing its allocated memory where applicable.

A. Delete the First Node

if (head != nullptr) {
    Node* temp = head;
    head = head->next;
    delete temp;
}

The old head is saved, head moves to the next node, and the old node is deleted. This takes O(1) time.

B. Delete a Middle Node

Find the node before the target node, change its next pointer to skip the target, and delete the target node. Finding the target usually takes O(n).

C. Delete the Last Node

For a singly linked list, find the second-last node, set its next pointer to nullptr, and delete the old last node. Special handling is needed if the list has zero or one node.

Always update links carefully before deleting nodes. Accessing a node after it has been deleted can cause undefined behavior.

8. Applications

  • Implementing stacks and queues.
  • Representing sequences that grow or shrink.
  • Moving forward and backward through items using doubly linked lists.
  • Representing graphs with adjacency lists.
  • Managing collections where insertions and deletions are frequent.
  • Building certain memory-management structures and playlists.

9. Advantages

  • Can grow or shrink dynamically.
  • Insertion and deletion at a known position can be efficient.
  • Does not require all nodes to be stored consecutively in memory.
  • Doubly linked lists support movement in both directions.

10. Disadvantages

  • Extra memory is needed for pointers.
  • No direct index-based access like an array.
  • Searching for a particular value usually takes O(n).
  • Pointer handling makes implementation more complex.
  • Nodes may have poorer cache locality than contiguous arrays.

12. Time Complexity

OperationSingly linked list
Access first nodeO(1)
Search by valueO(n)
Traverse all nodesO(n)
Insert at beginningO(1)
Delete at beginningO(1)
Insert at endO(n) with head only; O(1) with tail pointer

These costs assume a standard singly linked list. If the target node or its predecessor is already known, some insertion and deletion operations can be O(1).

Lesson Summary

  • A linked list consists of connected nodes.
  • A node stores data and one or more links.
  • Main types include singly, doubly and circular linked lists.
  • Insertion at the head is O(1); searching is generally O(n).
  • Linked lists are flexible, but pointer management needs care.
