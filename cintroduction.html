01. Introduction to C

C is a general-purpose programming language that is widely used for system programming, application development and learning programming fundamentals.

💡 What is C?

C is a structured programming language that allows programmers to write instructions that a computer can execute.

It is known for being fast, efficient and close to the hardware.

⭐ Features of C

  • Simple and structured
  • Fast and efficient
  • Portable
  • Supports functions
  • Provides low-level memory access
  • Widely used in system programming

💻 Your First C Program

Here is a simple C program that prints "Hello, World!" on the screen.

#include <stdio.h> int main() { printf("Hello, World!"); return 0; }

🔍 Understanding the Program

#include <stdio.h> gives access to standard input and output functions.

int main() is the starting point of the C program.

printf() is used to display output.

return 0; indicates that the program finished successfully.
