HTML Text Formatting

CS Companion | HTML Lesson 03

1. What is Text Formatting?

HTML text formatting tags change the appearance or meaning of text. We can make text bold, italic, highlighted, smaller, or display it as inserted or deleted text.

Example:

<p>This is <strong>important</strong> text.</p>

Output: This is important text.

3. Difference Between b and strong

Both <b> and <strong> usually appear bold in a browser.

  • b: Draws attention visually without adding importance by itself.
  • strong: Marks content as important.

4. Difference Between i and em

  • <i> is often used for alternate voice, terms, or titles.
  • <em> gives emphasis to words in a sentence.
