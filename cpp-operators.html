Operators in C++

Operators are symbols that perform operations on values and variables. C++ has arithmetic, comparison, logical and assignment operators.

1. Arithmetic Operators

int a = 10, b = 3;cout << a + b;  // 13
cout << a - b;  // 7
cout << a * b;  // 30
cout << a / b;  // 3
cout << a % b;  // 1

Note: Integer division 10 / 3 gives 3. The % operator gives the remainder.

2. Relational Operators

These compare values and return true or false.

a == b  // Equal to
a != b  // Not equal to
a > b   // Greater than
a < b   // Less than
a >= b  // Greater than or equal to
a <= b  // Less than or equal to

3. Logical Operators

&&  // AND
||  // OR
!   // NOT

4. Assignment Operators

int x = 5;
x += 3;  // x becomes 8
x -= 2;  // x becomes 6
x *= 2;  // x becomes 12

Complete Example

#include <iostream>
using namespace std;int main() {
int a = 10, b = 3;
cout << "Sum: " << a + b << endl;
cout << "Remainder: " << a % b << endl;
cout << (a > b);
return 0;
}

Expected Output

Sum: 13
Remainder: 1
1
