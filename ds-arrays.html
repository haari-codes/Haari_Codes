Arrays in C++

In this lesson, we will study array definition, characteristics, types, declaration, initialization, accessing elements, traversal, insertion and deletion concepts, applications, advantages, disadvantages and time complexity.

Learning objective: By the end, you should be able to declare arrays, access their elements and write simple array programs in C++.

1. Definition of Array

An array is a linear data structure that stores multiple elements of the same data type under a single name. Each element is accessed using an index.

Example: To store the marks of five students, we can use one array instead of five separate variables.

int marks[5] = {85, 90, 76, 88, 95};

Here, marks is an integer array containing five elements.

2. Characteristics of Arrays

  • Same data type: Elements in a normal C++ array have the same element type.
  • Index-based access: Elements are accessed by index.
  • Zero-based indexing: The first element is at index 0.
  • Fixed size: A built-in array's size cannot be changed after creation.
  • Contiguous storage: Array elements are stored in consecutive memory locations.
  • Direct access: An element can usually be accessed in constant time using its index.

For an array of size 5, valid indexes are 0, 1, 2, 3, 4. Index 5 is outside the array bounds.

3. Types of Arrays

A. One-Dimensional Array (1D)

A one-dimensional array stores elements in a single sequence.

int numbers[4] = {10, 20, 30, 40};

Indexes: 0, 1, 2, 3.

Applications: marks, temperatures, prices and lists of numbers.

B. Two-Dimensional Array (2D)

A two-dimensional array organizes elements in rows and columns. It is useful for tabular data and matrices.

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

This array has 2 rows and 3 columns. The element matrix[1][2] is 6.

C. Multidimensional Array

An array with three or more dimensions is called a multidimensional array.

int data[2][3][4];

This declares a three-dimensional array. Such arrays can represent data organized across multiple dimensions.

4. Array Declaration

Definition: Array declaration specifies the element type, array name and number of elements.

Syntax:

data_type array_name[size];

Example:

int age[5];
float prices[10];
char letters[4];
  • int, float and char are data types.
  • age, prices and letters are array names.
  • The number in square brackets specifies the number of elements.

5. Array Initialization

Definition: Initialization means assigning initial values to an array.

int marks[5] = {80, 75, 90, 85, 95};

We can also let the compiler determine the size from the initializer list:

int values[] = {10, 20, 30};

Here, the array has three elements.

In this example, the remaining elements are value-initialized to zero:

int numbers[5] = {1, 2};

The values are 1, 2, 0, 0, 0.

For local built-in arrays, declaring an array without initialization does not automatically make its elements zero.

6. Accessing and Updating Elements

Use the array name followed by an index in square brackets.

#include <iostream>
using namespace std;

int main() {
    int marks[3] = {80, 90, 75};

    cout << marks[0] << endl;
    cout << marks[2] << endl;

    marks[1] = 95;
    cout << marks[1];

    return 0;
}

Output:

80
75
95

marks[1] = 95; changes the second element. Remember that index 1 refers to the second element, not the first.

7. Traversing an Array

Traversal means visiting each element of an array, usually one by one.

#include <iostream>
using namespace std;

int main() {
    int a[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        cout << a[i] << " ";
    }

    return 0;
}

Output: 10 20 30 40 50

The loop starts at index 0 and stops before index 5. This prevents accessing an invalid index.

8. Insertion and Deletion

Insertion

Insertion means adding a new element at a particular position. In a basic fixed-size array, there must be an available slot. Elements may need to be shifted to make space.

Example: Inserting 25 into [10, 20, 30, 40] at index 2 requires shifting 30 and 40 to the right, producing [10, 20, 25, 30, 40].

Deletion

Deletion means removing an element from a logical list. Elements after it may need to shift left.

Example: Removing the element 20 from [10, 20, 30, 40] produces [10, 30, 40].

A built-in C++ array has a fixed capacity. Insertion and deletion in these examples change the logical contents, not the array's allocated size.

9. Applications of Arrays

  • Storing marks of students.
  • Representing matrices and tables.
  • Recording daily temperatures.
  • Storing lists of prices or scores.
  • Representing images as grids of pixels.
  • Serving as the basis for other algorithms and data structures.

10. Advantages of Arrays

  • Simple to understand and implement.
  • Accessing an element by index is fast, typically O(1).
  • Elements are stored contiguously, helping efficient iteration.
  • Useful for storing many values of the same type under one name.
  • Works well when the number of elements is known in advance.

11. Disadvantages of Arrays

  • A built-in array has a fixed size.
  • Inserting or deleting elements in the middle can require shifting elements.
  • Elements in a normal array must share the same element type.
  • Choosing an unnecessarily large size can waste space; choosing a size that is too small can limit capacity.
  • Accessing an invalid index causes undefined behavior in C++.

12. Time Complexity Basics

OperationTypical complexityExplanation
Access by indexO(1)Direct access to an element
Linear searchO(n)May inspect every element
TraversalO(n)Visits all n elements
Insertion in the middleO(n)May shift many elements
Deletion in the middleO(n)May shift later elements

These are typical worst-case costs for a simple array implementation. Actual costs depend on the operation and assumptions.

Lesson Summary

  • An array stores elements of the same type under one name.
  • Array indexes start at zero in C++.
  • Common forms are 1D, 2D and multidimensional arrays.
  • Declaration defines the array; initialization supplies initial values.
  • Index access is fast, but insertion and deletion can require shifting elements.
