C++ Arrays

An array is a collection of elements of the same data type stored under one name. Each element is accessed using an index.

1. Declaring an Array

We specify the data type, array name and number of elements.

int marks[5];

This creates an integer array that can store five values. Array indexing starts at 0, so the indexes are 0, 1, 2, 3 and 4.

2. Initialising an Array

#include <iostream>
using namespace std;int main() {
int numbers[5] = {10, 20, 30, 40, 50};

cout << numbers[0] << endl;
cout << numbers[2] << endl;
return 0;

}

Output:

10
30

numbers[0] accesses the first element. numbers[2] accesses the third element.

3. Changing an Array Element

int numbers[3] = {5, 10, 15};
numbers[1] = 25;
cout << numbers[1];

Output:

25

We can change an element by assigning a new value to its index.

4. Using a for Loop with Arrays

A loop helps us access every element without writing a separate statement for each one.

#include <iostream>
using namespace std;int main() {
int numbers[4] = {10, 20, 30, 40};

for (int i = 0; i < 4; i++) {
    cout << numbers[i] << " ";
}

return 0;

}

Output:

10 20 30 40

The loop starts at index 0 and continues while i < 4.

5. Finding the Sum of Array Elements

#include <iostream>
using namespace std;int main() {
int numbers[4] = {2, 4, 6, 8};
int sum = 0;

for (int i = 0; i < 4; i++) {
    sum = sum + numbers[i];
}

cout << "Sum = " << sum;
return 0;

}

Output:

Sum = 20

6. Introduction to Strings

A string stores a sequence of characters. In C++, we can use the string type from the string library.

#include <iostream>
#include <string>
using namespace std;int main() {
string name = "Haari Codes";
cout << name;
return 0;
}

Output:

Haari Codes

Remember

  • All elements in an array have the same data type.
  • Array indexing starts from 0.
  • The last index of an array of size 5 is 4.
  • Loops are useful for accessing array elements.
  • Never access an index outside the array's valid range.
