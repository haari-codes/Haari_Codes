07. Functions

📘 What is a Function?

A function is a block of code that performs a specific task. It helps us divide a large program into smaller, manageable parts.

Advantages of functions:

  • Code reusability
  • Easy debugging
  • Better program organization
  • Less code repetition

🧩 Types of Functions

C functions can be broadly classified into:

  • Library functions: Predefined functions such as printf() and scanf().
  • User-defined functions: Functions created by the programmer.
Example: 
printf("Hello");

Here, printf() is a library function used to display output.

1️⃣ Function Declaration

A function declaration tells the compiler the function's name, return type and parameters. 

int add(int, int);

Here, int is the return type, add is the function name, and the two integers are its parameters.

2️⃣ Function Definition

A function definition contains the actual statements that perform the task. 

int add(int a, int b)
{
    return a + b;
}

This function receives two integers and returns their sum.

3️⃣ Function Call

A function call executes the function. We call a function using its name and arguments. 

int result = add(10, 20);

Here, 10 and 20 are passed to the function. The returned value, 30, is stored in result.

💻 Complete Example Program

#include <stdio.h>

int add(int, int);

int main()
{
    int result;

    result = add(10, 20);

    printf("Sum = %d", result);

    return 0;
}

int add(int a, int b)
{
    return a + b;
}
Output:

Sum = 30

📌 Parameters and Arguments

Parameters: Variables listed in the function definition.

Arguments: Actual values passed when the function is called. 

int add(int a, int b)
{
    return a + b;
}

add(5, 3);

In this example, a and b are parameters. The values 5 and 3 are arguments.

↩️ Return Value

The return statement sends a value back to the calling function. 

int square(int n)
{
    return n * n;
}

Calling square(4) returns 16.
