Semantic HTML Elements

CS Companion | HTML Lesson 08

1. What Is Semantic HTML?

Semantic HTML uses elements that describe the meaning and purpose of their content.

For example, <nav> identifies a navigation area, while <footer> identifies footer information.

Why use semantic elements?

  • Make code easier to understand and maintain.
  • Help screen readers interpret webpage structure.
  • Make page sections clearer for developers and browsers.
  • Provide meaningful structure for search engines.

Compare these examples:

<div>Menu links go here</div>

<nav>Menu links go here</nav>

Both can contain links, but <nav> communicates that the content is a navigation section.

2. Important Semantic Elements

1. <header>

Contains introductory content, such as a page title, logo or introductory links. A page or section can have its own header.

<header>
  <h1>My Website</h1>
  <p>Welcome!</p>
</header>

2. <nav>

Contains a major group of navigation links.

<nav>
  <a href="index.html">Home</a>
  <a href="about.html">About</a>
</nav>

3. <main>

Contains the main, unique content of the page. Normally, a page has one visible <main> element.

<main>
  <h2>Main Content</h2>
  <p>Page information goes here.</p>
</main>

4. <section>

Groups related content, often under a heading.

<section>
  <h2>Our Courses</h2>
  <p>Explore our courses.</p>
</section>

5. <article>

Represents a self-contained piece of content that could make sense independently, such as a blog post or news article.

<article>
  <h2>Learning HTML</h2>
  <p>HTML structures webpages.</p>
</article>

6. <aside>

Contains related or supplementary content, such as a sidebar or a related-links section.

<aside>
  <h3>Related Topics</h3>
  <p>Learn CSS next.</p>
</aside>

7. <footer>

Contains footer information for a page or section, such as copyright details or related links.

<footer>
  <p>Copyright 2026</p>
</footer>

4. Section vs Article vs Div

  • section: Groups related content under a common topic.
  • article: Contains independent, self-contained content.
  • div: A generic container without built-in semantic meaning, often used for styling or layout.
<section>
  <h2>Latest Posts</h2>

  <article>
    <h3>Post One</h3>
    <p>Post content...</p>
  </article>
</section>

<div class="purple-box">
  Styled content
</div>

Choose the element based on the meaning of the content, not just its appearance.

5. Common Mistakes

  • Using <nav> for every group of links, even when it is not a major navigation area.
  • Using <section> as a generic styling container without a clear topic.
  • Putting the main page content outside <main> unnecessarily.
  • Choosing an element because of its default appearance instead of its meaning.

Semantic elements do not automatically create a particular design. Use CSS to control colours, spacing and layout.
