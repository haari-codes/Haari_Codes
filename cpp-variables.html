Variables & Data Types

A variable is a named storage location used to hold a value. A data type determines what kind of value a variable can store.

Common Data Types

  • int: whole numbers, such as 18
  • float: decimal numbers, such as 92.5
  • char: a single character, such as 'A'
  • string: text, such as "Haari"
  • bool: true or false

Code Example

#include <iostream>
#include <string>
using namespace std;int main() {
int age = 18;
float mark = 92.5;
char grade = 'A';
string name = "Haari";
bool passed = true;

cout << name << endl;
cout << age << endl;
cout << mark << endl;
cout << grade << endl;
cout << passed;
return 0;

}

Expected Output

Haari
18
92.5
A
1

Remember: C++ prints a bool value as 1 for true and 0 for false by default.
