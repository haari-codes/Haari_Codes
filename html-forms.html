HTML Forms

CS Companion | HTML Lesson 07

1. What Is an HTML Form?

An HTML form collects information from users. Forms are commonly used for registration, login, feedback and search.

<form action="/submit" method="post">
  <label for="username">Username:</label>
  <input type="text" id="username"
         name="username">
  <button type="submit">Submit</button>
</form>

Important attributes:

  • action: specifies where form data should be sent.
  • method: specifies how data is sent, commonly using GET or POST.
  • name: identifies a field when its data is submitted.
  • id: uniquely identifies an element within the page.

Important: A real form submission needs a suitable server or form-handling service. HTML alone does not store submitted data in a database.

2. Text Input

The input element collects different kinds of user information.

<label for="name">Name:</label>
<input type="text" id="name" name="name">

3. Common Input Types

  • text: ordinary text.
  • password: hides characters as they are typed.
  • email: accepts an email address and provides basic browser validation.
  • number: numeric input.
  • date: date selection.
  • radio: choose one option from a group.
  • checkbox: choose one or more options.
  • file: select a file.
  • submit: submit a form.
  • reset: reset fields to their initial values.
<input type="email" name="email">
<input type="password" name="password">
<input type="number" name="age">

4. Radio Buttons

Radio buttons let the user select one option from a group. Use the same name for options belonging to the same group.

<label>
  <input type="radio" name="course" value="C">
  C Programming
</label>
<label>
  <input type="radio" name="course" value="SQL">
  SQL
</label>

6. Dropdown Lists

A dropdown list uses <select> and <option>.

<select name="subject">
  <option value="c">C Programming</option>
  <option value="sql">SQL</option>
</select>

7. Textarea and Buttons

<textarea> collects longer text, such as comments or feedback.

<textarea name="feedback"
          rows="4"
          placeholder="Write feedback">
</textarea>

<button type="submit">Submit</button>
<button type="reset">Reset</button>
  • rows controls the visible number of text lines.
  • placeholder displays a hint inside an empty field.
  • required makes a field mandatory during browser validation.
