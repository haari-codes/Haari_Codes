1. What is CSS?

CSS stands for Cascading Style Sheets. It controls how HTML elements look on a webpage.

  • HTML creates the structure and content.
  • CSS controls colours, fonts, spacing, borders and layout.
  • JavaScript adds behaviour and interactivity.

2. CSS Syntax

p {
  color: purple;
  font-size: 18px;
}

Every CSS rule contains a selector and a declaration block.

  • p is the selector. It targets paragraph elements.
  • color is a property.
  • purple is the property's value.
  • A semicolon separates declarations.

3. Three Ways to Add CSS

Inline CSS

<p style="color: purple;">Hello!</p>

CSS is written directly inside an HTML element's style attribute.

Internal CSS

<head>
  <style>
    p { color: purple; }
  </style>
</head>

CSS is written inside a <style> element in the HTML document.

External CSS

<head>
  <link rel="stylesheet" href="style.css">
</head>

CSS is saved in a separate file, such as style.css. External CSS is especially useful for styling multiple pages consistently.

4. CSS Selectors

/* Element selector */
p { color: purple; }/* Class selector */
.note { background: lavender; }

/* ID selector */
#heading { font-size: 28px; }
  • Element selector: targets all elements of that type.
  • Class selector: starts with a dot (.) and can be reused.
  • ID selector: starts with # and should identify one unique element on a page.

5. Common CSS Properties

  • color: text colour.
  • background-color: background colour.
  • font-size: text size.
  • font-family: font style.
  • text-align: text alignment.
  • margin: space outside an element.
  • padding: space inside an element's border.
  • border: draws a border.
  • width and height: control dimensions.

6. Margin vs Padding

Margin creates space outside an element. Padding creates space between the content and its border.

.card {
  margin: 20px;
  padding: 15px;
  border: 2px solid purple;
}

Remember: margin = outside space; padding = inside space.
