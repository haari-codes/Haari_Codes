11. Structures

📘 What is a Structure?

A structure is a user-defined data type in C that groups related variables, possibly of different data types, under one name.

Real-life example:

A student has a name, roll number and mark. We can group these details using a structure. 

Name: Haari
Roll Number: 101
Mark: 95

1️⃣ Structure Declaration

We use the keyword struct to declare a structure. 

struct Student
{
    char name[30];
    int roll;
    float mark;
};

Here, Student is the structure tag. It contains three members: name, roll and mark.

  • char name[30]: Stores the name.
  • int roll: Stores the roll number.
  • float mark: Stores the mark.

Notice the semicolon after the closing brace. It is required in a structure declaration.

2️⃣ Declaring a Structure Variable

After defining the structure type, we can declare variables of that type. 

struct Student s1;

Here, s1 is a structure variable. It can hold the name, roll number and mark of one student.

3️⃣ Structure Initialization

We can assign initial values when declaring a structure variable. 

struct Student
{
    char name[30];
    int roll;
    float mark;
};

struct Student s1 = {"Haari", 101, 95.5f};
Values stored in s1: 
name = Haari
roll = 101
mark = 95.5

4️⃣ Accessing Structure Members

The dot operator . is used to access members of a structure variable. 

s1.roll = 101;
s1.mark = 95.5f;

printf("%d", s1.roll);
printf("%.1f", s1.mark);
Output: 
101
95.5

s1.roll accesses the roll member. s1.mark accesses the mark member.

5️⃣ Complete Example Program

#include <stdio.h>

struct Student
{
    char name[30];
    int roll;
    float mark;
};

int main()
{
    struct Student s1 = {"Haari", 101, 95.5f};

    printf("Name: %s\n", s1.name);
    printf("Roll: %d\n", s1.roll);
    printf("Mark: %.1f\n", s1.mark);

    return 0;
}
Output: 
Name: Haari
Roll: 101
Mark: 95.5

6️⃣ Pointer to a Structure

A structure pointer stores the address of a structure variable. 

struct Student s1 = {"Haari", 101, 95.5f};

struct Student *p = &s1;

Here, p points to the structure variable s1.

7️⃣ Arrow Operator (->)

The arrow operator -> accesses a structure member through a pointer. 

printf("%d", p->roll);
Output:

101

p->roll is equivalent to (*p).roll.

📌 Important Points

  • struct is used to define a structure type.
  • A structure can contain different data types.
  • The dot operator accesses members through a structure variable.
  • A structure pointer stores the address of a structure.
  • The arrow operator accesses members through a pointer.
