06. Loops

🔁 What is a Loop?

A loop is used to execute a block of code repeatedly until a particular condition becomes false.

In C, the main types of loops are:

  • for loop
  • while loop
  • do-while loop

1️⃣ for Loop

The for loop is commonly used when we know how many times the loop should execute. 

for(initialization; condition; update)
{
    // statements
}
Example: 
#include <stdio.h>

int main()
{
    int i;

    for(i = 1; i <= 5; i++)
    {
        printf("%d ", i);
    }

    return 0;
}

Output: 1 2 3 4 5

2️⃣ while Loop

The while loop executes the statements as long as the condition is true. 

while(condition)
{
    // statements
}
Example: 
int i = 1;

while(i <= 5)
{
    printf("%d ", i);
    i++;
}

Output: 1 2 3 4 5

3️⃣ do-while Loop

The do-while loop executes the statements at least once before checking the condition. 

do
{
    // statements
}
while(condition);
Example: 
int i = 1;

do
{
    printf("%d ", i);
    i++;
}
while(i <= 5);

Output: 1 2 3 4 5

📌 Difference Between Loops

  • for: Best when the number of iterations is known.
  • while: Condition is checked before execution.
  • do-while: Executes at least once.
