Introduction to Data Structures

Welcome to Lesson 1! In this lesson, we will learn what data structures are, why they are needed, their types, real-life applications and basic examples.

Learning objectives: By the end of this lesson, you should be able to define a data structure, classify its types, compare common structures and explain why they are useful.

1. Definition of Data Structure

A data structure is a particular way of organizing, storing and managing data in a computer so that it can be accessed and modified efficiently.

For example, imagine storing the marks of 50 students. Keeping each mark in a separate variable would be inconvenient. An array can store all 50 marks under one name.

int marks[5] = {85, 90, 76, 88, 95};

Here, marks is an array that stores five integer values.

2. Why Do We Need Data Structures?

  • Organize data: Keep information arranged in a useful form.
  • Access data: Find the required information efficiently.
  • Insert and delete: Add or remove data when needed.
  • Process large data: Manage many records systematically.
  • Improve efficiency: Choose a suitable structure to reduce time or memory usage.

Example: A music player can use a list of songs. A browser can maintain a history of visited pages. Different tasks may benefit from different data structures.

3. Classification of Data Structures

A. Primitive Data Structures

Primitive data types are the basic built-in types used to represent individual values.

  • int: whole numbers, such as 10
  • char: a character, such as 'A'
  • float: decimal values, such as 3.5
  • bool: true or false

B. Non-Primitive Data Structures

These organize collections of values or relationships between data.

  • Arrays
  • Linked Lists
  • Stacks
  • Queues
  • Trees
  • Graphs

C. Linear Data Structures

Elements are arranged in a sequence, one after another.

Examples: Array, Linked List, Stack and Queue.

10 → 20 → 30 → 40

D. Non-Linear Data Structures

Elements are arranged in hierarchical or network-like relationships rather than a single sequence.

Examples: Trees and Graphs.

        A
       / \
      B   C
     / \
    D   E

5. Advantages of Data Structures

  • Organize information systematically.
  • Make searching, insertion, deletion or updating efficient when the appropriate structure is chosen.
  • Help manage large amounts of information.
  • Support the design of algorithms and software applications.
  • Can improve memory usage and processing time.

6. Disadvantages and Limitations

  • Some structures are difficult to understand and implement.
  • Some operations require extra memory, such as pointers in linked lists.
  • A poorly chosen structure can make operations slower.
  • Some structures have restrictions, such as the fixed capacity of a basic fixed-size array.
  • Maintaining relationships between elements can make code more complex.

Remember: No single data structure is best for every situation. The right choice depends on the operations your program needs.

7. Real-Life Applications

  • Stack: Undo and redo operations in editors.
  • Queue: Tasks waiting to be processed.
  • Tree: Folder and file organization.
  • Graph: Maps, routes and social networks.
  • Hash table: Looking up information using a key.
  • Array: Storing marks, temperatures or daily measurements.

Lesson Summary

  • A data structure organizes and manages data.
  • Primitive types represent basic values; non-primitive structures organize data collections or relationships.
  • Linear structures include arrays, linked lists, stacks and queues.
  • Non-linear structures include trees and graphs.
  • Choose a structure based on the operations and requirements of the problem.
