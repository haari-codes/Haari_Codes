HTML Lists

CS Companion | HTML Lesson 05

1. What Is a List?

An HTML list displays related items in an organised format. Lists are useful for menus, instructions, shopping lists and many other things.

HTML provides three main types of lists:

  • Ordered List
  • Unordered List
  • Description List

2. Ordered List

An ordered list displays items in a sequence, usually using numbers.

Tags: <ol> and <li>

<ol>
  <li>Wake up</li>
  <li>Study</li>
  <li>Sleep</li>
</ol>

Output:

  1. Wake up
  2. Study
  3. Sleep

Changing the numbering style

<ol type="A">
  <li>Apple</li>
  <li>Mango</li>
</ol>

Common type values:

  • 1: 1, 2, 3
  • A: A, B, C
  • a: a, b, c
  • I: I, II, III
  • i: i, ii, iii

You can also use start="5" to begin numbering at 5.

3. Unordered List

An unordered list displays items with bullets rather than a numbered sequence.

Tags: <ul> and <li>

<ul>
  <li>Notebook</li>
  <li>Pen</li>
  <li>Pencil</li>
</ul>

Output:

  • Notebook
  • Pen
  • Pencil

CSS can change bullet styles:

<ul style="list-style-type: square;">
  <li>Notebook</li>
  <li>Pen</li>
</ul>

Other styles include disc, circle and none.

4. Description List

A description list presents terms and their descriptions.

Tags:

  • <dl>: description list
  • <dt>: description term
  • <dd>: description or definition
<dl>
  <dt>HTML</dt>
  <dd>Structures a webpage.</dd>

  <dt>CSS</dt>
  <dd>Styles a webpage.</dd>
</dl>

Output:

HTML
Structures a webpage.
CSS
Styles a webpage.

5. Nested Lists

A nested list is a list placed inside another list item. It helps organise subtopics.

<ul>
  <li>Programming
    <ul>
      <li>C</li>
      <li>C++</li>
    </ul>
  </li>
  <li>Database
    <ul>
      <li>SQL</li>
    </ul>
  </li>
</ul>

Output:

  • Programming
    • C
    • C++
  • Database
    • SQL

Remember to place the nested list inside its parent <li> element.
