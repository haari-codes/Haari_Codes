SQL Subqueries

A query inside another query

1. What is a Subquery?

A subquery is an SQL query written inside another SQL statement. It is also called an inner query or nested query.

The query containing the subquery is called the outer query.

Consider this table named Employees:

2. Subquery with a Comparison Operator

Question: Find employees whose salary is greater than the average salary.

SELECT name, salary
FROM Employees
WHERE salary > (
    SELECT AVG(salary)
    FROM Employees
);

How it works:

  1. The inner query calculates the average salary: 29000.
  2. The outer query selects employees whose salary is greater than 29000.

Expected result: Anu (30000) and Meera (40000).

The parentheses contain the subquery. In this example, it returns one value, so it can be compared using >.

3. Single-Row Subquery

A single-row subquery returns one row. A single-value result can be used with operators such as =, >, and <.

Example: Find the employee earning the highest salary by comparing salaries with the maximum salary.

SELECT name, salary
FROM Employees
WHERE salary = (
    SELECT MAX(salary)
    FROM Employees
);

Expected result: Meera, 40000.

If multiple employees share the maximum salary, all matching employees are returned.

4. Multi-Row Subquery with IN

Use IN when the subquery can return multiple values.

Question: Find employees who work in a department that has an employee earning more than 35000.

SELECT name, department
FROM Employees
WHERE department IN (
    SELECT department
    FROM Employees
    WHERE salary > 35000
);

The inner query returns IT. The outer query finds all employees in IT.

Expected result: Anu (IT) and Meera (IT).

5. Subquery with ANY and ALL

These operators compare a value against the results of a subquery. The exact syntax and support may vary by database.

ANY

> ANY means the value is greater than at least one value returned by the subquery.

SELECT name, salary
FROM Employees
WHERE salary > ANY (
    SELECT salary
    FROM Employees
    WHERE department = 'HR'
);

HR salaries are 25000 and 28000. The condition is true when salary is greater than at least one of them, so salaries greater than 25000 qualify.

ALL

> ALL means the value must be greater than every value returned by the subquery.

SELECT name, salary
FROM Employees
WHERE salary > ALL (
    SELECT salary
    FROM Employees
    WHERE department = 'HR'
);

This finds employees earning more than both HR salaries, meaning more than 28000.

For exams, remember: ANY means at least one; ALL means every value.

6. Subquery with EXISTS

EXISTS checks whether a subquery returns at least one row.

Suppose we have a table named Departments with a column called department.

SELECT D.department
FROM Departments D
WHERE EXISTS (
    SELECT 1
    FROM Employees E
    WHERE E.department = D.department
);

This returns departments that have at least one matching employee.

NOT EXISTS can be used to find departments without any matching employees.

SELECT D.department
FROM Departments D
WHERE NOT EXISTS (
    SELECT 1
    FROM Employees E
    WHERE E.department = D.department
);

7. Correlated Subquery

A correlated subquery refers to a column from the outer query. It depends on the current outer row and is conceptually evaluated for each candidate row, though a database may optimize its execution.

Question: Find employees whose salary is greater than the average salary of their own department.

SELECT E.name, E.department, E.salary
FROM Employees E
WHERE E.salary > (
    SELECT AVG(E2.salary)
    FROM Employees E2
    WHERE E2.department = E.department
);

Expected result:

  • Meera: IT average is 35000, and her salary is 40000.
  • Arun: HR average is 26500, and his salary is 28000.

E and E2 are aliases for the Employees table. The inner query uses E.department from the outer query.

8. Subquery in the FROM Clause

A subquery in the FROM clause creates a temporary result set for the outer query. Many databases call this a derived table.

SELECT department, average_salary
FROM (
    SELECT department,
           AVG(salary) AS average_salary
    FROM Employees
    GROUP BY department
) AS DepartmentAverages
WHERE average_salary > 25000;

The inner query calculates the average salary for each department. The outer query keeps departments whose average salary is greater than 25000.

Expected result: HR (26500) and IT (35000).

In MySQL, a derived table in the FROM clause needs a table alias, such as DepartmentAverages.

9. Subquery vs JOIN

SubqueryJOIN
Contains a query inside another query.Combines rows from tables using a join condition.
Useful for comparing with averages, maximums, or sets of values.Useful for displaying related columns from multiple tables.

Both approaches can sometimes solve the same problem. The clearest and most efficient option depends on the query, database, indexes, and data.

10. Common Mistakes

  • Forgetting parentheses around a subquery.
  • Using = when a subquery may return multiple rows. Consider IN, ANY, ALL, or EXISTS as appropriate.
  • Forgetting to give a derived table an alias when the database requires it.
  • Using a column name that is ambiguous between the inner and outer queries. Use table aliases to clarify.
  • Assuming a subquery always runs separately for every row. The database optimizer may transform or optimize it.

11. Quick Revision

  • Subquery: A query inside another query.
  • Single-value subquery: Returns one value for comparison.
  • IN: Checks membership in a set of values.
  • ANY: Condition matches at least one returned value.
  • ALL: Condition matches every returned value.
  • EXISTS: Checks whether any row exists.
  • Correlated subquery: Refers to a column from the outer query.
  • Derived table: A subquery in the FROM clause.
