Data Structures | Lesson 04

Stack

A stack is a linear data structure in which insertion and deletion take place at the same end, called the top.

Learning objectives: Understand LIFO, stack operations, the top variable, overflow and underflow, array implementation, algorithms, complexity and real-life applications.

1. Definition of Stack

A stack is a linear data structure that follows the LIFO (Last In, First Out) principle. The last element inserted is the first element removed.

Think of a stack of plates. The last plate placed on top is normally the first plate taken off.

       TOP
        |
      [30] ← Last inserted
      [20]
      [10] ← First inserted

If we push 10, then 20, then 30, the first pop removes 30.

2. Important Terminology

  • TOP: Indicates the position of the top element.
  • Push: Inserts an element at the top.
  • Pop: Removes the top element.
  • Peek/Top: Reads the top element without removing it.
  • Overflow: Trying to push into a full fixed-capacity stack.
  • Underflow: Trying to pop from an empty stack.

3. Array Representation of a Stack

Suppose we have an array of capacity 5. We use a variable called top to track the top element.

int stack[5];
int top = -1;

Why is top = -1?

Array indexes begin at 0. When the stack is empty, no valid index contains a stack element, so we use -1 to represent the empty stack.

Stack stateTOP value
Empty-1
One element0
Two elements1
Five elements in capacity 54

For a stack with capacity N, the array is full when top == N - 1, and empty when top == -1.

4. Stack Operations

A. Push

Push adds a new element to the top of the stack.

if (top == capacity - 1) {
    // Stack Overflow
} else {
    top++;
    stack[top] = value;
}

First check whether the stack is full. If not, increment top and store the value.

B. Pop

Pop removes the top element.

if (top == -1) {
    // Stack Underflow
} else {
    int removed = stack[top];
    top--;
}

First check whether the stack is empty. If it is not empty, read the top value and decrement top.

In a basic array stack, decrementing top removes the element from the logical stack. The old value may still remain in the array memory, but it is no longer part of the stack.

C. Peek

Peek reads the top element without removing it.

if (top == -1) {
    // Stack is empty
} else {
    cout << stack[top];
}

D. isEmpty and isFull

bool isEmpty = (top == -1);
bool isFull = (top == capacity - 1);

5. Step-by-Step Example

Assume the capacity is 5 and initially top = -1.

The pop operation removes 30 because it was the last element inserted.

6. Algorithms

Algorithm: PUSH(STACK, TOP, ITEM)

  1. If TOP == MAX - 1, report Overflow and stop.
  2. Set TOP = TOP + 1.
  3. Set STACK[TOP] = ITEM.
  4. Stop.

Algorithm: POP(STACK, TOP)

  1. If TOP == -1, report Underflow and stop.
  2. Store STACK[TOP] in ITEM.
  3. Set TOP = TOP - 1.
  4. Return ITEM.

For exams, write the algorithm steps clearly and mention the overflow or underflow condition.

7. Complete C++ Program

This program implements push, pop, peek and display operations.

#include <iostream>
using namespace std;

const int CAPACITY = 5;
int stackArr[CAPACITY];
int top = -1;

void push(int value) {
    if (top == CAPACITY - 1) {
        cout << "Stack Overflow\n";
        return;
    }
    stackArr[++top] = value;
    cout << value << " pushed\n";
}

void pop() {
    if (top == -1) {
        cout << "Stack Underflow\n";
        return;
    }
    cout << "Removed: " << stackArr[top--] << "\n";
}

void peek() {
    if (top == -1) {
        cout << "Stack is empty\n";
    } else {
        cout << "Top: " << stackArr[top] << "\n";
    }
}

void display() {
    if (top == -1) {
        cout << "Stack is empty\n";
        return;
    }

    cout << "Top to bottom: ";
    for (int i = top; i >= 0; i--) {
        cout << stackArr[i] << " ";
    }
    cout << "\n";
}

int main() {
    push(10);
    push(20);
    push(30);
    display();
    peek();
    pop();
    display();

    return 0;
}

Output:

10 pushed
20 pushed
30 pushed
Top to bottom: 30 20 10
Top: 30
Removed: 30
Top to bottom: 20 10

8. Types / Implementations of Stack

A. Array-based Stack

Uses an array and a top variable. It is simple and provides a fixed capacity unless a resizable structure is used.

B. Linked-list-based Stack

Uses nodes connected by pointers. The head can act as the top, allowing push and pop at the head in O(1) time. It grows dynamically until memory resources become limiting.

C. Call Stack

Programming languages use a call stack to manage active function calls, including return information and local execution state.

9. Applications of Stack

  • Undo and redo operations in editors.
  • Browser history navigation in suitable implementations.
  • Function calls and recursion.
  • Expression evaluation and conversion.
  • Checking balanced brackets in expressions.
  • Backtracking algorithms and depth-first search.
  • Reversing data such as a sequence of characters.

10. Advantages

  • Simple to implement.
  • Push and pop are typically O(1).
  • Useful for reversing and backtracking tasks.
  • Helps manage nested function calls and expressions.

11. Disadvantages

  • A fixed-size array stack has limited capacity.
  • Trying to pop an empty stack causes underflow.
  • Only the top element is directly accessible through normal stack operations.
  • A linked-list stack needs extra memory for pointers.
  • Incorrect recursion or excessive calls can exhaust the program's call stack.

Lesson Summary

  • A stack follows LIFO.
  • Push inserts, pop removes, and peek reads the top element.
  • For a basic array stack, top starts at -1.
  • Overflow occurs when pushing into a full fixed-capacity stack; underflow occurs when removing from an empty stack.
  • Push, pop and peek are typically O(1).
