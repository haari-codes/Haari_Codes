🗄️ Lesson 03: DML Commands

Haari_Codes | Insert, update and delete records

1. What is DML?

DML stands for Data Manipulation Language.

DML commands are used to add, modify and remove records stored in database tables.

Main commands

  • INSERT: Adds new records.
  • UPDATE: Modifies existing records.
  • DELETE: Removes records.
In this lesson, we will use a Students table to understand each command.

2. Our Sample Table

Assume this table already exists:

CREATE TABLE Students (
    id INT,
    name VARCHAR(50),
    mark INT
);

We will use the following records for our examples.

idnamemark
1Anu90
2Akhil85
3Meera95

The table is assumed to contain these three records before each independent example unless stated otherwise.

3. INSERT Command

The INSERT command adds new records to a table.

A. Insert values into every column

INSERT INTO Students
VALUES (4, 'Rahul', 88);

This inserts a new student with ID 4, name Rahul and mark 88.

B. Insert values into selected columns

INSERT INTO Students (id, name)
VALUES (5, 'Diya');

This inserts a record with ID 5 and name Diya. The mark column receives NULL if no default is defined and the column permits NULL.

C. Insert multiple records

INSERT INTO Students (id, name, mark)
VALUES
(6, 'Nila', 91),
(7, 'Arun', 84);

This adds two records in one statement in database systems that support this syntax.

Important rules

  • Text values are usually written inside single quotes.
  • Numeric values usually do not need quotes.
  • When values are supplied for every column without naming columns, their order must match the table definition.
  • Explicitly listing column names often makes INSERT statements clearer and safer.

4. UPDATE Command

The UPDATE command modifies existing records.

Syntax

UPDATE table_name
SET column_name = value
WHERE condition;

Example: Update one student's mark

UPDATE Students
SET mark = 92
WHERE id = 1;

This changes Anu's mark from 90 to 92 because the record has ID 1.

Example: Update more than one column

UPDATE Students
SET name = 'Ananya', mark = 96
WHERE id = 1;

This changes the name and mark for the record whose ID is 1.

What happens without WHERE?

UPDATE Students
SET mark = 0;

This sets the mark of every record in the table to 0.

Important safety rule: Always check your WHERE condition before running UPDATE. Without WHERE, all rows are affected.

5. DELETE Command

The DELETE command removes records from a table.

Syntax

DELETE FROM table_name
WHERE condition;

Example: Delete one record

DELETE FROM Students
WHERE id = 2;

This removes the record whose ID is 2, if it exists.

Example: Delete records that match a condition

DELETE FROM Students
WHERE mark < 40;

This removes all records whose mark is less than 40.

What happens without WHERE?

DELETE FROM Students;

This removes all records from Students, but the table structure remains.

Be careful: A DELETE statement without WHERE can remove every record. Check the condition and the target table before running it.

6. INSERT vs UPDATE vs DELETE

CommandPurposeExample
INSERTAdds new recordsINSERT INTO Students ...
UPDATEChanges existing recordsUPDATE Students SET ...
DELETERemoves recordsDELETE FROM Students ...

Remember this example

  • New student joins college → INSERT
  • Student's mark is corrected → UPDATE
  • A student record must be removed → DELETE

7. Using SELECT to Check Changes

After inserting, updating or deleting records, use SELECT to inspect the table.

SELECT * FROM Students;

To view only the name and mark columns:

SELECT name, mark
FROM Students;

To view one particular student:

SELECT *
FROM Students
WHERE id = 1;

SELECT is commonly classified as DQL, while INSERT, UPDATE and DELETE are commonly classified as DML.

8. Common Mistakes

  • Forgetting single quotes around text values.
  • Providing values in the wrong column order.
  • Using UPDATE without checking the WHERE condition.
  • Using DELETE without WHERE when only one record should be removed.
  • Forgetting that a condition may match multiple records.
  • Assuming a successful query always affects exactly one row.
Tip: Before changing or deleting records, run a SELECT query with the same WHERE condition to check which records match.

📌 Lesson Summary

  • INSERT adds records to a table.
  • UPDATE modifies existing records.
  • DELETE removes matching records.
  • WHERE helps target particular records.
  • Without WHERE, UPDATE and DELETE can affect every record.
  • SELECT can be used to inspect records before and after changes.
