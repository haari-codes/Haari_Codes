🔎 Lesson 04: SELECT & Filtering

Haari_Codes | Retrieve, filter and sort data

1. What is SELECT?

The SELECT statement retrieves data from one or more database tables.

It is one of the most frequently used SQL statements.

General syntax

SELECT column1, column2
FROM table_name;

Select every column

SELECT *
FROM Students;

The asterisk (*) means all columns in the selected table.

Select specific columns

SELECT name, mark
FROM Students;

This displays only the name and mark columns.

Tip: In large tables, selecting only the columns you need can be clearer and more efficient than using SELECT *.

3. DISTINCT

DISTINCT returns unique combinations of the selected column values, removing duplicate result rows.

Syntax

SELECT DISTINCT column_name
FROM table_name;

Example

SELECT DISTINCT city
FROM Students;

Expected result

city
Kochi
Thrissur
Calicut

The city Kochi and Thrissur each appear only once in the result, even though multiple students live there.

The order of results is not guaranteed unless you use ORDER BY.

DISTINCT on multiple columns

SELECT DISTINCT city, mark
FROM Students;

This returns unique city-and-mark combinations, not unique cities alone.

4. WHERE Clause

The WHERE clause filters rows according to a condition.

Syntax

SELECT column_names
FROM table_name
WHERE condition;

Example 1: Students scoring more than 80

SELECT name, mark
FROM Students
WHERE mark > 80;

Expected result

namemark
Anu90
Meera95

Example 2: Find students from Kochi

SELECT *
FROM Students
WHERE city = 'Kochi';

Example 3: Find students scoring 75

SELECT name
FROM Students
WHERE mark = 75;

This returns Akhil and Diya.

Common comparison operators

<>Not equal to

Text values are commonly enclosed in single quotes. SQL comparisons with NULL need special conditions such as IS NULL, which we will study in the next lesson.

5. ORDER BY

ORDER BY sorts the rows in the query result.

A. Ascending order

SELECT name, mark
FROM Students
ORDER BY mark ASC;

ASC means ascending. For numbers, this means smallest to largest. ASC is the default sort direction when no direction is specified.

Expected result

namemark
Rahul60
Akhil75
Diya75
Anu90
Meera95

Rows with the same mark may appear in either order unless an additional sort column is specified.

B. Descending order

SELECT name, mark
FROM Students
ORDER BY mark DESC;

DESC means descending. For numbers, this means largest to smallest.

C. Sort by multiple columns

SELECT name, city, mark
FROM Students
ORDER BY city ASC, mark DESC;

This sorts by city first, then sorts marks from highest to lowest within each city.

6. LIMIT

LIMIT restricts the number of rows returned. It is supported by MySQL, PostgreSQL and SQLite, among others.

Syntax

SELECT column_names
FROM table_name
LIMIT number;

Example: Show only the first three rows

SELECT *
FROM Students
LIMIT 3;

This returns up to three rows. Without ORDER BY, the database does not guarantee which rows will be first.

Example: Find the two highest marks

SELECT name, mark
FROM Students
ORDER BY mark DESC
LIMIT 2;

Expected result

namemark
Meera95
Anu90
SQL dialects differ. SQL Server commonly uses TOP or OFFSET/FETCH, while standard SQL supports FETCH FIRST in suitable systems.

7. Combining WHERE, ORDER BY and LIMIT

You can combine these clauses to answer more specific questions.

Example: Top two marks above 70

SELECT name, mark
FROM Students
WHERE mark > 70
ORDER BY mark DESC
LIMIT 2;

Expected result

namemark
Meera95
Anu90

Logical order of processing

For a simple SELECT query, the conceptual processing order is:

  1. FROM: Choose the source table.
  2. WHERE: Filter rows.
  3. SELECT: Choose the output columns.
  4. ORDER BY: Sort the result.
  5. LIMIT: Restrict the number of rows returned.
This is a simplified logical order, not necessarily the order in which a database physically executes every operation.

8. Common Mistakes

  • Forgetting FROM when selecting from a table.
  • Using double equals (==) instead of the SQL equality operator (=).
  • Forgetting quotes around text values.
  • Expecting DISTINCT city to show every student.
  • Using LIMIT without ORDER BY when a specific top result is needed.
  • Expecting a fixed order when ORDER BY is missing.

📌 Lesson Summary

  • SELECT retrieves data.
  • DISTINCT removes duplicate result rows.
  • WHERE filters rows using conditions.
  • ORDER BY sorts query results using ASC or DESC.
  • LIMIT restricts the number of returned rows in supported systems.
  • Combine these clauses to find exactly the information you need.
