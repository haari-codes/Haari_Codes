🗄️ Lesson 02: DDL Commands

Haari_Codes | Define and modify database structures

1. What is DDL?

DDL stands for Data Definition Language.

DDL is a category of SQL commands used to create, change or remove database objects such as tables.

Main DDL Commands

  • CREATE: Creates a database object.
  • ALTER: Changes the structure of an existing object.
  • DROP: Removes a database object.
  • TRUNCATE: Removes all records from a table while keeping its structure.
Remember: DDL mainly deals with the structure of database objects, not individual record editing.

2. CREATE Command

The CREATE command creates database objects, such as databases and tables.

Syntax

CREATE TABLE table_name (
    column1 datatype,
    column2 datatype
);

Example

CREATE TABLE Students (
    id INT,
    name VARCHAR(50),
    mark INT
);

This creates a table named Students with three columns: id, name and mark.

Insert some sample data

INSERT INTO Students VALUES (1, 'Anu', 90);
INSERT INTO Students VALUES (2, 'Akhil', 85);

The INSERT statements are DML commands. They add records to the table created by CREATE.

View the records

SELECT * FROM Students;
Expected result
idnamemark
1Anu90
2Akhil85

3. ALTER Command

The ALTER command changes the structure of an existing table.

A. Add a column

ALTER TABLE Students
ADD age INT;

This adds an age column to Students. Existing rows will have NULL in that column unless a default or other database-specific rule applies.

B. Change a column definition

The syntax depends on the database system. For example, in MySQL:

ALTER TABLE Students
MODIFY name VARCHAR(100);

This changes the permitted length of the name column to 100 characters in MySQL.

Other systems use different syntax. For example, PostgreSQL uses ALTER COLUMN with TYPE for changing a column's data type.

C. Drop a column

ALTER TABLE Students
DROP COLUMN age;

This removes the age column and its stored values. Make sure you no longer need the data before running it.

4. DROP Command

The DROP command removes a database object, such as a table.

Syntax

DROP TABLE table_name;

Example

DROP TABLE Students;

This removes the Students table itself, including its records and structure.

Warning: DROP TABLE is destructive. You generally cannot retrieve the dropped table without a backup or recovery mechanism.

5. TRUNCATE Command

The TRUNCATE command removes all records from a table but preserves the table structure.

Syntax

TRUNCATE TABLE Students;

After truncation, the table still exists with the same columns, but it contains no records.

Transaction behaviour, identity-counter resets and restrictions differ between database systems. Do not assume TRUNCATE can always be rolled back.

6. DROP vs TRUNCATE vs DELETE

Command Effect Keeps table?
DROPRemoves table and recordsNo
TRUNCATERemoves all recordsYes
DELETERemoves selected or all recordsYes

Example: DELETE with a condition

DELETE FROM Students
WHERE id = 1;

This removes the record whose id is 1, if it exists. The table remains, and other records are unaffected.

Example: DELETE all records

DELETE FROM Students;

This removes all records but leaves the table structure intact.

Exam tip: DELETE is generally classified as DML. DROP, TRUNCATE and CREATE are commonly classified as DDL.

7. Advantages of DDL

  • Creates tables and other database objects.
  • Allows the table structure to evolve.
  • Helps remove objects that are no longer needed.
  • Supports organizing data using suitable columns and data types.

8. Precautions

  • Check the table name before running DROP or TRUNCATE.
  • Back up important data before destructive changes.
  • Check dependencies, constraints and permissions.
  • Use the correct syntax for your database system.

📌 Lesson Summary

  • CREATE creates database objects.
  • ALTER changes the structure of existing objects.
  • DROP removes a database object.
  • TRUNCATE removes all records but keeps the table structure.
  • DELETE removes selected records or all records, depending on the query.
