08. Arrays

📘 What is an Array?

An array is a collection of elements of the same data type stored under a single name.

Instead of creating separate variables for multiple values, we can store them in an array.

Example:

Imagine you have marks for five subjects. An array can store all five marks using one name. 

int marks[5] = {80, 75, 90, 85, 70};

1️⃣ Array Declaration

The general syntax is:

data_type array_name[size];

Example:

int numbers[5];
float prices[10];
char letters[4];
  • int: Data type
  • numbers: Array name
  • 5: Number of elements

2️⃣ Array Initialization

Initialization means assigning initial values to the array elements. 

int numbers[5] = {10, 20, 30, 40, 50};
Array elements: 
Index:    0   1   2   3   4
Value:   10  20  30  40  50

Important: In C, array indexing starts from 0. Therefore, an array of five elements has indices from 0 to 4.

3️⃣ Accessing Array Elements

We can access an element using the array name and its index. 

int numbers[5] = {10, 20, 30, 40, 50};

printf("%d", numbers[0]);
printf("%d", numbers[2]);
Output: 
10
30

numbers[0] gives 10. numbers[2] gives 30.

4️⃣ Traversing an Array

Traversing means visiting each element of an array, usually using a loop. 

#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};
    int i;

    for(i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    return 0;
}
Output:

10 20 30 40 50

5️⃣ Reading Array Elements

We can use a loop with scanf() to read values from the user. 

int numbers[5];
int i;

for(i = 0; i < 5; i++)
{
    scanf("%d", &numbers[i]);
}

The expression &numbers[i] gives the address where the input value should be stored.

📌 Important Points

  • All elements normally have the same data type.
  • Array indexing starts from 0.
  • The last valid index is size minus 1.
  • Array elements can be accessed using their indices.
  • Loops make it easier to process arrays.
