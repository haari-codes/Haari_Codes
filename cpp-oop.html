Object-Oriented Programming (OOP)

Object-Oriented Programming is a programming approach that organises code using classes and objects. C++ supports OOP concepts that help us build reusable and organised programs.

1. What Is a Class?

A class is a blueprint for creating objects. It can contain data members and member functions.

class Student {
public:
    string name;
    int age;
};

Here, Student is a class with two data members: name and age.

2. What Is an Object?

An object is an instance of a class.

#include <iostream>
#include <string>
using namespace std;class Student {
public:
string name;
int age;
};

int main() {
Student s1;
s1.name = "Haari";
s1.age = 19;

cout << s1.name << endl;
cout << s1.age;

return 0;

}

Output:

Haari
19

s1 is an object of the Student class. The dot operator accesses its members.

3. Encapsulation

Encapsulation combines data and functions inside a class. Access specifiers such as private help control access to data.

class BankAccount {
private:
    int balance = 1000;public:
int getBalance() {
return balance;
}
};

The balance member is private, so it cannot be accessed directly from outside the class. The public function provides access to its value.

4. Inheritance

Inheritance allows one class to acquire accessible members from another class.

class Animal {
public:
    void eat() {
        cout << "Eating";
    }
};class Dog : public Animal {
};

Dog inherits from Animal and can use its public eat() function.

5. Polymorphism

Polymorphism means “many forms”. It allows the same function name or interface to behave differently in different situations.

#include <iostream>
using namespace std;class Animal {
public:
virtual void sound() {
cout << "Animal sound";
}
};

class Dog : public Animal {
public:
void sound() override {
cout << "Bark";
}
};

int main() {
Dog d;
Animal* ptr = &d;
ptr->sound();
return 0;
}

Output:

Bark

The virtual function lets the derived class provide its own implementation.

6. Abstraction

Abstraction means showing essential features while hiding unnecessary implementation details. In C++, abstract classes can be created using pure virtual functions.

class Shape {
public:
    virtual void draw() = 0;
};

Shape is an abstract class. We cannot create an object of it directly, and a concrete derived class must implement draw().

OOP Concepts: Quick Revision

  • Class: Blueprint for objects.
  • Object: An instance of a class.
  • Encapsulation: Combines data and functions and controls access.
  • Inheritance: Builds a class using another class.
  • Polymorphism: One interface, different behaviours.
  • Abstraction: Hides implementation details and exposes essential features.
