04. Input & Output

Input and output are important concepts in C programming. They allow a program to communicate with the user.

📤 Output in C

The printf() function is used to display output on the screen.

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}
Remember:

printf() → displays output

📥 Input in C

The scanf() function is commonly used to take input from the user.

#include <stdio.h>

int main()
{
    int age;

    scanf("%d", &age);

    return 0;
}
Remember:

scanf() → takes input from the user

🔤 Format Specifiers

Format specifiers tell C what type of data is being input or output.

%d → int

%f → float

%c → char

%s → string

💻 Example Program

#include <stdio.h>

int main()
{
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Your age is %d", age);

    return 0;
}
