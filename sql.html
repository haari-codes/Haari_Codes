Welcome to SQL! 💻

SQL stands for Structured Query Language. It is used to create, manage, retrieve and manipulate data stored in relational databases.

In this course, you will learn SQL from the basics to more advanced concepts through explanations, examples, queries and quizzes.

What you will learn

  • How databases and tables work

  • How to use keys, constraints, views and indexes

📌 SQL Basics

What is a database?

A database is an organized collection of data that can be stored, accessed and managed efficiently.

What is a table?

A table stores data in rows and columns. Each row represents a record, and each column represents an attribute.

Example SQL query

CREATE TABLE Students (
    id INT,
    name VARCHAR(50),
    mark INT
);

INSERT INTO Students
VALUES (1, 'Anu', 90);

SELECT * FROM Students;

The SELECT query retrieves all columns from the Students table.

Note: SQL syntax can vary slightly between MySQL, PostgreSQL, SQLite and other database systems.
