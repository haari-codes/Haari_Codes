Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on web pages.

HTML tells the browser what content is present, such as headings, paragraphs, images, links, lists and forms.

Remember: HTML creates the structure, CSS controls the appearance, and JavaScript adds interactivity.

1. What is HTML?

  • HTML is a markup language, not a programming language.
  • It uses elements represented by tags.
  • Browsers read HTML and display the page.
  • HTML files commonly use the .html extension.

2. Basic Structure of an HTML Document

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Page</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>This is my first webpage.</p>
</body>
</html>

Explanation

  • <!DOCTYPE html> declares an HTML document using modern HTML.
  • <html> is the root element.
  • <head> contains metadata and page information.
  • <title> sets the browser tab title.
  • <body> contains the visible page content.
  • <h1> creates a main heading.
  • <p> creates a paragraph.

3. HTML Tags and Elements

A tag is written inside angle brackets. Many HTML elements have an opening tag, content and a closing tag.

<p>Welcome to Haari Codes!</p>
  • <p> is the opening tag.
  • Welcome to Haari Codes! is the content.
  • </p> is the closing tag.

Some elements, such as <br> and <img>, do not need a separate closing tag.

4. HTML Attributes

Attributes provide extra information about an element. They are usually written in the opening tag.

<a href="https://example.com">Visit Website</a>

<img src="flower.jpg"
     alt="A flower">
  • href specifies a link destination.
  • src specifies an image source.
  • alt provides alternative text for an image.

5. Common HTML Tags

  • <h1> to <h6>: headings
  • <p>: paragraph
  • <a>: hyperlink
  • <img>: image
  • <br>: line break
  • <ul> and <ol>: lists
  • <li>: list item
  • <div>: generic block container
