02. Variables & Data Types

Variables and data types are fundamental concepts in C programming. They help us store and work with different kinds of data.

💡 What is a Variable?

A variable is a named memory location used to store a value that can change during program execution.

Every variable in C has a data type, a name and a value.

int age = 18;

🧩 Parts of a Variable

int age = 18;

int → Data type

age → Variable name

18 → Value

📦 Common Data Types

Data Type Used For Example
int Whole numbers 25
float Decimal numbers 3.14
char Single character 'A'
double Large decimal values 25.6789

💻 Example Program

#include <stdio.h> int main() { int age = 18; float height = 1.65; char grade = 'A'; printf("Age: %d\n", age); printf("Height: %.2f\n", height); printf("Grade: %c\n", grade); return 0; }
