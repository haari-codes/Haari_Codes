Audio & Video in HTML 🎧

CS Companion | HTML Lesson 09

1. Introduction

HTML can display audio and video directly on a webpage. The <audio> element plays sound, while <video> displays video.

  • <audio> for music, recordings and sound effects.
  • <video> for lessons, clips and demonstrations.
  • <source> specifies the media file and its format.

2. Adding Audio

<audio controls>
  <source src="music.mp3" type="audio/mpeg">
  Your browser does not support audio.
</audio>

Explanation:

  • controls displays play, pause and volume controls.
  • src identifies the audio file.
  • type tells the browser the media format.

Common audio formats include MP3, WAV and OGG. Browser support can vary.

3. Adding Video

<video controls width="400" poster="cover.jpg">
  <source src="lesson.mp4" type="video/mp4">
  Your browser does not support video.
</video>
  • controls shows video playback controls.
  • width sets the displayed width.
  • poster displays a preview image before playback.
  • height can set the displayed height.

Common video formats include MP4 and WebM. Codec and browser support affect playback.

4. Important Media Attributes

  • controls: shows playback controls.
  • autoplay: requests automatic playback. Browsers often block autoplay with sound, so avoid relying on it.
  • muted: starts the media without sound.
  • loop: repeats playback.
  • preload: hints whether media should load before playback.
<video controls muted loop width="320">
  <source src="clip.mp4" type="video/mp4">
</video>

Use autoplay carefully, and give users control over media playback.

5. Captions and Subtitles

The <track> element can provide captions or subtitles for a video, usually using a WebVTT file.

<video controls width="400">
  <source src="lesson.mp4" type="video/mp4">
  <track src="captions.vtt"
         kind="captions"
         srclang="en"
         label="English">
</video>

Captions make videos more accessible, including for people who cannot hear the audio.

6. Embedding an Online Video

You can embed a video from a service that permits embedding using an <iframe>. For example, YouTube provides an embed URL.

<iframe
  width="560"
  height="315"
  src="https://www.youtube.com/embed/VIDEO_ID"
  title="HTML lesson video"
  allowfullscreen>
</iframe>

Replace VIDEO_ID with the actual video ID. Use the provider's official embed code and a meaningful title. Do not paste a normal watch-page URL where an embed URL is required.
