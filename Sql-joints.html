1. What is a JOIN?

A JOIN combines rows from two or more tables using a related column or a specified matching condition.

Suppose we have two tables.

Students

3Meera

Marks

The common column is student_id. We can use it to connect the tables.

2. INNER JOIN

INNER JOIN returns only rows that have matching values in both tables.

SELECT Students.name, Marks.subject, Marks.mark
FROM Students
INNER JOIN Marks
ON Students.student_id = Marks.student_id;

Expected result:

namesubjectmark
AnuComputer Science90
RahulMathematics85

Meera is not included because she has no matching row in Marks. The marks row with student_id 4 is also excluded because no student matches it.

Remember: INNER JOIN = matching rows from both tables.

3. LEFT JOIN

LEFT JOIN returns every row from the left table and matching rows from the right table. If no match exists, right-table columns contain NULL.

SELECT Students.name, Marks.subject, Marks.mark
FROM Students
LEFT JOIN Marks
ON Students.student_id = Marks.student_id;

Expected result:

namesubjectmark
AnuComputer Science90
RahulMathematics85
MeeraNULLNULL

All students appear, including Meera, who has no matching marks record.

Remember: LEFT JOIN = all rows from the left table, plus matching rows from the right.

4. RIGHT JOIN

RIGHT JOIN returns every row from the right table and matching rows from the left table. If no match exists, left-table columns contain NULL.

SELECT Students.name, Marks.subject, Marks.mark
FROM Students
RIGHT JOIN Marks
ON Students.student_id = Marks.student_id;

Expected result:

namesubjectmark
AnuComputer Science90
RahulMathematics85
NULLEnglish78

The English marks row appears even though no student matches student_id 4.

Remember: RIGHT JOIN = all rows from the right table, plus matching rows from the left.

5. FULL OUTER JOIN

FULL OUTER JOIN returns all matching rows and all unmatched rows from both tables. Missing values are shown as NULL.

SELECT Students.name, Marks.subject, Marks.mark
FROM Students
FULL OUTER JOIN Marks
ON Students.student_id = Marks.student_id;

Conceptual result:

namesubjectmark
AnuComputer Science90
RahulMathematics85
MeeraNULLNULL
NULLEnglish78
Important: MySQL does not directly support FULL OUTER JOIN. In MySQL, you can combine a LEFT JOIN with a RIGHT JOIN using UNION, or use a LEFT JOIN plus a query for unmatched right-side rows. Other database systems may support FULL OUTER JOIN directly.

MySQL alternative

SELECT Students.name, Marks.subject, Marks.mark
FROM Students
LEFT JOIN Marks
ON Students.student_id = Marks.student_id

UNION ALL

SELECT Students.name, Marks.subject, Marks.mark
FROM Students
RIGHT JOIN Marks
ON Students.student_id = Marks.student_id
WHERE Students.student_id IS NULL;

This keeps the left-join results and adds only unmatched right-side rows, avoiding duplicates from matching rows.

6. CROSS JOIN

CROSS JOIN returns every possible combination of rows from the two tables. It is also called a Cartesian product.

SELECT Students.name, Marks.subject
FROM Students
CROSS JOIN Marks;

There are 3 students and 3 marks rows, so the result contains 3 × 3 = 9 combinations.

Use CROSS JOIN carefully. Large tables can produce a very large result.

7. SELF JOIN

A SELF JOIN joins a table with itself. It is useful for relationships within one table, such as employees and their managers.

Imagine an Employees table with employee_id, name, and manager_id.

SELECT E.name AS employee,
       M.name AS manager
FROM Employees E
LEFT JOIN Employees M
ON E.manager_id = M.employee_id;

E and M are aliases for the same table. The query lists employees and their managers. Employees without a manager still appear because LEFT JOIN is used.

8. JOIN with WHERE and ORDER BY

JOINs can be combined with other SQL clauses.

SELECT Students.name, Marks.mark
FROM Students
INNER JOIN Marks
ON Students.student_id = Marks.student_id
WHERE Marks.mark >= 85
ORDER BY Marks.mark DESC;

This returns matching students with marks of 85 or above, sorted from highest mark to lowest.

ON vs WHERE

  • ON specifies how rows match between tables.
  • WHERE filters the result according to a condition.
With OUTER JOINs, putting a condition on the right table in WHERE can remove unmatched rows and change the result. Put conditions in ON when you want to preserve all rows from the outer side.

10. Common Mistakes

  • Forgetting the ON condition in a regular join, which can produce unintended combinations.
  • Joining on unrelated columns.
  • Assuming INNER JOIN includes unmatched rows.
  • Forgetting that unmatched columns in an outer join can be NULL.
  • Using FULL OUTER JOIN directly in MySQL, which does not support it as a native join type.
  • Using unclear column names when both tables have columns with the same name. Use table names or aliases, such as Students.student_id.

11. Quick Revision

  • INNER: Matching rows only.
  • LEFT: All left rows, plus matches.
  • RIGHT: All right rows, plus matches.
  • FULL: All rows from both sides.
  • CROSS: Every possible combination.
  • SELF: A table joined to itself.
  • ON: Defines the matching condition.
  • WHERE: Filters rows in the result.
