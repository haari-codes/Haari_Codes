Queue

A queue is a linear data structure in which elements are added at one end and removed from the other end.

Learning objectives: Understand FIFO, front and rear, enqueue and dequeue, types of queues, algorithms, C++ implementation, applications and complexity.

1. Definition of Queue

A queue is a linear data structure that follows the FIFO (First In, First Out) principle. The first element inserted is the first element removed.

Real-life example: People waiting in a normal line. The person who joins first is generally served first.

DEQUEUE ← [10] [20] [30] ← ENQUEUE
           FRONT       REAR

Here, 10 is removed first, while a new element is added at the rear.

2. Important Terminology

  • Front: Position of the element that will be removed next.
  • Rear: Position of the most recently inserted element.
  • Enqueue: Add an element at the rear.
  • Dequeue: Remove an element from the front.
  • Peek: Read the front element without removing it.
  • Overflow: Trying to add an element to a full fixed-capacity queue.
  • Underflow: Trying to remove an element from an empty queue.

3. Types of Queues

A. Linear Queue

Insertion takes place at the rear, and deletion takes place at the front.

FRONT → [10] [20] [30] ← REAR

In a simple array implementation, deleted spaces at the beginning may remain unused until the queue is reset or elements are shifted. This can cause a false overflow when the rear reaches the last array index.

B. Circular Queue

The last array position connects logically back to the first position. This lets the queue reuse spaces freed by dequeue operations.

   [0] → [1] → [2]
    ↑           ↓
   [5] ← [4] ← [3]

For an array of capacity N, the next position is calculated using (index + 1) % N.

C. Priority Queue

Each element has a priority. Elements are removed according to priority rather than strictly by arrival order. When priorities are equal, the implementation may preserve arrival order.

Application: Scheduling tasks according to importance.

D. Double-Ended Queue (Deque)

A deque allows insertion and deletion at both the front and rear.

Application: Sliding-window algorithms and systems that need access at both ends.

4. Array Representation

A simple linear queue can use an array and two variables called front and rear.

int queue[5];
int front = -1;
int rear = -1;

When the queue is empty, both variables are initially -1 in this simple implementation.

  • When the first element is inserted, set both front and rear to 0.
  • When another element is inserted, increment rear.
  • When an element is removed, increment front.
  • If the last element is removed, reset both variables to -1.

These rules describe a simple linear queue. Circular queues use different empty/full conditions.

5. Enqueue Operation

Enqueue inserts a new element at the rear of the queue.

  1. Check whether the queue is full.
  2. If the queue is empty, set front to 0.
  3. Increment rear.
  4. Store the new element at queue[rear].
if (rear == capacity - 1) {
    // Overflow
} else {
    if (front == -1)
        front = 0;

    rear++;
    queue[rear] = item;
}

This is a basic linear queue algorithm. It does not reuse freed spaces at the beginning.

6. Dequeue Operation

Dequeue removes the front element.

  1. Check whether the queue is empty.
  2. Store the front element if needed.
  3. If front equals rear, reset both to -1.
  4. Otherwise, increment front.
if (front == -1) {
    // Underflow
} else {
    int item = queue[front];

    if (front == rear) {
        front = rear = -1;
    } else {
        front++;
    }
}

7. Complete C++ Program: Linear Queue

#include <iostream>
using namespace std;

const int CAPACITY = 5;
int q[CAPACITY];
int frontIndex = -1;
int rearIndex = -1;

void enqueue(int value) {
    if (rearIndex == CAPACITY - 1) {
        cout << "Queue Overflow\n";
        return;
    }

    if (frontIndex == -1)
        frontIndex = 0;

    q[++rearIndex] = value;
    cout << value << " enqueued\n";
}

void dequeue() {
    if (frontIndex == -1) {
        cout << "Queue Underflow\n";
        return;
    }

    cout << "Removed: " << q[frontIndex] << "\n";

    if (frontIndex == rearIndex) {
        frontIndex = rearIndex = -1;
    } else {
        frontIndex++;
    }
}

void peek() {
    if (frontIndex == -1)
        cout << "Queue is empty\n";
    else
        cout << "Front: " << q[frontIndex] << "\n";
}

void display() {
    if (frontIndex == -1) {
        cout << "Queue is empty\n";
        return;
    }

    cout << "Front to rear: ";
    for (int i = frontIndex; i <= rearIndex; i++)
        cout << q[i] << " ";

    cout << "\n";
}

int main() {
    enqueue(10);
    enqueue(20);
    enqueue(30);

    display();
    peek();
    dequeue();
    display();

    return 0;
}

Output:

10 enqueued
20 enqueued
30 enqueued
Front to rear: 10 20 30
Front: 10
Removed: 10
Front to rear: 20 30

Limitation: This basic linear array queue does not reuse freed slots at the start until the queue becomes empty. A circular queue solves that space-reuse problem.

8. Circular Queue: Key Conditions

In a circular queue of capacity N, the rear can wrap around to index 0.

Next index:

next = (index + 1) % N;

For the common implementation that tracks the number of elements:

  • Empty when count == 0.
  • Full when count == N.
  • Enqueue at rear, then update rear using modulo N.
  • Dequeue at front, then update front using modulo N.

This approach avoids confusion between a full queue and an empty queue.

9. Applications of Queues

  • Printer job scheduling.
  • Customer-service waiting lines.
  • CPU and process scheduling systems.
  • Network packet buffering.
  • Breadth-first search (BFS) in graphs.
  • Handling tasks in the order they arrive.
  • Message processing systems.

10. Advantages

  • Maintains FIFO order.
  • Enqueue and dequeue can be O(1) with a suitable implementation.
  • Useful for scheduling and buffering tasks.
  • Circular queues reuse array positions efficiently.

11. Disadvantages

  • A simple fixed-size array queue has limited capacity.
  • A basic linear queue can waste usable spaces at the beginning.
  • Priority queues require priority-management logic.
  • Incorrect front/rear updates can cause errors.
  • Linked-list queues require additional pointer memory.

Lesson Summary

  • A queue follows FIFO.
  • Enqueue inserts at the rear; dequeue removes from the front.
  • Front identifies the next element to remove.
  • Circular queues reuse array positions efficiently.
  • Queues are used in scheduling, buffering and BFS.
