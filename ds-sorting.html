Lesson 7: Sorting Algorithms

1. What Is Sorting?

Sorting is the process of arranging data in a particular order, usually ascending or descending.

Ascending order: smallest to largest.

Example: [5, 2, 8, 1] becomes [1, 2, 5, 8].

Descending order: largest to smallest.

Example: [5, 2, 8, 1] becomes [8, 5, 2, 1].

Why is sorting useful?

  • Makes data easier to understand.
  • Can make searching more efficient.
  • Helps organise student marks, names, prices and records.
  • Is used in databases and many software applications.

In this lesson, we study five common sorting algorithms.

2. Bubble Sort

Definition

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order. After each pass, a large element moves towards the end of the array in ascending sorting.

Example

Start: [5, 3, 8, 2]

Pass 1:

  • Compare 5 and 3: swap → [3, 5, 8, 2]
  • Compare 5 and 8: no swap.
  • Compare 8 and 2: swap → [3, 5, 2, 8]

Pass 2: Compare 3 and 5, then 5 and 2. Result: [3, 2, 5, 8].

Pass 3: Swap 3 and 2. Final result: [2, 3, 5, 8].

Algorithm

  1. Start at the first element.
  2. Compare each pair of adjacent elements.
  3. Swap if the left element is greater than the right.
  4. Repeat passes until the array is sorted.

C++ Program

#include <iostream>
using namespace std;

int main() {
    int a[] = {5, 3, 8, 2};
    int n = 4;

    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;

        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
                swapped = true;
            }
        }

        if (!swapped) break;
    }

    for (int i = 0; i < n; i++)
        cout << a[i] << " ";

    return 0;
}

Output: 2 3 5 8

Advantages

  • Easy to learn and implement.
  • Can stop early if no swaps are needed.

Disadvantages

  • Slow for large datasets.
  • May require many comparisons and swaps.

3. Selection Sort

Definition

Selection Sort repeatedly finds the smallest element in the unsorted part and places it at the beginning of that part.

Example

Start: [5, 3, 8, 2]

  1. Smallest is 2. Swap it with 5 → [2, 3, 8, 5].
  2. In the remaining part [3, 8, 5], smallest is 3. Leave it in place.
  3. In [8, 5], smallest is 5. Swap → [2, 3, 5, 8].

Algorithm

  1. Assume the first unsorted element is the smallest.
  2. Scan the remaining elements to find the actual smallest.
  3. Swap it with the first unsorted element.
  4. Repeat for the remaining unsorted section.

C++ Program

#include <iostream>
using namespace std;

int main() {
    int a[] = {5, 3, 8, 2};
    int n = 4;

    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;

        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[minIndex])
                minIndex = j;
        }

        int temp = a[i];
        a[i] = a[minIndex];
        a[minIndex] = temp;
    }

    for (int i = 0; i < n; i++)
        cout << a[i] << " ";

    return 0;
}

Output: 2 3 5 8

Advantages

  • Simple to understand.
  • Uses very little extra memory.
  • Performs at most a linear number of swaps.

Disadvantages

  • Still performs many comparisons even if the array is nearly sorted.
  • Not efficient for large datasets.

4. Insertion Sort

Definition

Insertion Sort builds a sorted section one element at a time. Each new element is inserted into its correct position among the previously sorted elements.

Think of arranging playing cards in your hand: pick up one card and insert it where it belongs.

Example

Start: [5, 3, 8, 2]

  1. Start with 5 as the sorted section.
  2. Insert 3 before 5 → [3, 5, 8, 2].
  3. 8 is already in the correct place → [3, 5, 8, 2].
  4. Insert 2 at the beginning → [2, 3, 5, 8].

C++ Program

#include <iostream>
using namespace std;

int main() {
    int a[] = {5, 3, 8, 2};
    int n = 4;

    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;

        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
        }

        a[j + 1] = key;
    }

    for (int i = 0; i < n; i++)
        cout << a[i] << " ";

    return 0;
}

Output: 2 3 5 8

Advantages

  • Simple and efficient for small arrays.
  • Works well when the data is already nearly sorted.
  • Uses constant extra space.

Disadvantages

  • Can be slow for large, reverse-sorted arrays.
  • May shift many elements to insert one value.

5. Merge Sort

Definition

Merge Sort uses the divide-and-conquer technique. It divides the array into smaller parts, sorts those parts, and merges them into one sorted array.

Example

Original: [8, 3, 5, 2]

  1. Divide into [8, 3] and [5, 2].
  2. Divide further into [8], [3], [5], [2].
  3. Merge sorted pairs: [3, 8] and [2, 5].
  4. Merge them: [2, 3, 5, 8].

Core idea in pseudocode

MERGE_SORT(array)
    if array has 0 or 1 element
        return array

    divide array into left and right
    MERGE_SORT(left)
    MERGE_SORT(right)
    merge left and right in sorted order

C++ Program

#include <iostream>
using namespace std;

void merge(int a[], int left, int mid, int right) {
    int n1 = mid - left + 1;
    int n2 = right - mid;
    int L[n1], R[n2];

    for (int i = 0; i < n1; i++)
        L[i] = a[left + i];

    for (int j = 0; j < n2; j++)
        R[j] = a[mid + 1 + j];

    int i = 0, j = 0, k = left;

    while (i < n1 && j < n2) {
        if (L[i] <= R[j])
            a[k++] = L[i++];
        else
            a[k++] = R[j++];
    }

    while (i < n1)
        a[k++] = L[i++];

    while (j < n2)
        a[k++] = R[j++];
}

void mergeSort(int a[], int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        mergeSort(a, left, mid);
        mergeSort(a, mid + 1, right);
        merge(a, left, mid, right);
    }
}

int main() {
    int a[] = {8, 3, 5, 2};
    int n = 4;

    mergeSort(a, 0, n - 1);

    for (int i = 0; i < n; i++)
        cout << a[i] << " ";

    return 0;
}

Output: 2 3 5 8

Note: The temporary arrays above are supported by many C++ compilers as an extension, but variable-length arrays are not standard C++. For strictly standard C++, use vector or dynamically allocated temporary arrays.

Advantages

  • Reliable O(n log n) time even in the worst case.
  • Suitable for large datasets.
  • Stable when implemented with equal elements taken from the left half first.

Disadvantages

  • Requires additional memory for merging an array.
  • Implementation is more complex than simple sorting methods.

6. Quick Sort

Definition

Quick Sort also uses divide-and-conquer. It selects a value called a pivot, partitions the elements around that pivot, and recursively sorts the parts.

In ascending order, values smaller than or equal to the pivot are placed on its left, and larger values on its right, depending on the partition method.

Example concept

Array: [5, 3, 8, 2, 7]

Choose pivot 5. One possible partition is [3, 2] 5 [8, 7]. Sort both sides: [2, 3, 5, 7, 8].

The exact intermediate order depends on the partition algorithm and chosen pivot.

C++ Program

#include <iostream>
using namespace std;

int partition(int a[], int low, int high) {
    int pivot = a[high];
    int i = low - 1;

    for (int j = low; j < high; j++) {
        if (a[j] <= pivot) {
            i++;
            int temp = a[i];
            a[i] = a[j];
            a[j] = temp;
        }
    }

    int temp = a[i + 1];
    a[i + 1] = a[high];
    a[high] = temp;

    return i + 1;
}

void quickSort(int a[], int low, int high) {
    if (low < high) {
        int p = partition(a, low, high);
        quickSort(a, low, p - 1);
        quickSort(a, p + 1, high);
    }
}

int main() {
    int a[] = {5, 3, 8, 2, 7};
    int n = 5;

    quickSort(a, 0, n - 1);

    for (int i = 0; i < n; i++)
        cout << a[i] << " ";

    return 0;
}

Output: 2 3 5 7 8

Advantages

  • Usually fast in practice.
  • Typically uses less extra array storage than Merge Sort.

Disadvantages

  • A poor pivot choice can lead to O(n²) worst-case time.
  • Recursive calls use stack memory.
  • This implementation is not stable in general.

7. Time and Space Complexity

Time complexity describes how running time grows with input size. Space complexity describes the extra memory required by the algorithm.

AlgorithmBest TimeAverage TimeWorst TimeExtra Space
Bubble Sort (with early stop)O(n)O(n²)O(n²)O(1)
Selection SortO(n²)O(n²)O(n²)O(1)
Insertion SortO(n)O(n²)O(n²)O(1)
Merge SortO(n log n)O(n log n)O(n log n)O(n)
Quick SortO(n log n)O(n log n)O(n²)Typically O(log n) stack on balanced partitions; worst O(n)

The table describes common implementations. Actual performance can depend on the input, pivot choice, and implementation details.
