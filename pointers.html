10. Pointers

📘 What is a Pointer?

A pointer is a variable that stores the memory address of another object, such as a variable.

Simple idea:

A normal variable stores a value. A pointer stores the address where that value is located.

Variable x Value: 10
Pointer p Stores x's address

The actual memory address depends on the computer and program execution.

1️⃣ Pointer Declaration

General syntax:

data_type *pointer_name;

Example:

int *p;
float *q;
char *r;

Here, p can point to an int object, q to a float object, and r to a char object.

The asterisk in a declaration indicates that the variable is a pointer.

2️⃣ Address Operator (&)

The address operator & gives the memory address of a variable. 

int x = 10;

printf("%p", (void *)&x);

Here, &x means the address of x. The actual address may differ each time.

3️⃣ Pointer Initialization

We can initialize a pointer using the address of a compatible variable. 

int x = 10;
int *p = &x;

Now p stores the address of x.

Remember:

Make sure a pointer is initialized to a valid object or set to NULL before dereferencing it.

4️⃣ Dereference Operator (*)

The dereference operator * accesses the value of the object pointed to by a valid pointer. 

int x = 10;
int *p = &x;

printf("%d", *p);
Output:

10

Since p points to x, *p gives the value stored in x.

5️⃣ Complete Example Program

#include <stdio.h>

int main()
{
    int x = 10;
    int *p = &x;

    printf("Value of x = %d\n", x);
    printf("Value using pointer = %d\n", *p);

    *p = 25;

    printf("Updated value of x = %d\n", x);

    return 0;
}
Output: 
Value of x = 10
Value using pointer = 10
Updated value of x = 25

When we write *p = 25, we change the value of x because p points to x.

6️⃣ Important Difference

int x = 10;
int *p = &x;
  • x: The value of the variable is 10.
  • &x: The address of x.
  • p: The address stored in the pointer.
  • *p: The value of x, which is 10.

📌 Quick Revision

  • A pointer stores an address.
  • & is the address-of operator.
  • * is used to declare a pointer and to dereference it in expressions.
  • Dereferencing an invalid pointer causes undefined behaviour.
  • A pointer can modify a variable through its address.
