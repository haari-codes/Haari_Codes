Data Structures

Data structures are ways of organizing and storing data so that it can be accessed and modified efficiently. This course covers important data structures and algorithms using simple explanations, examples, C++ code, applications and practice questions.

What you will learn: Arrays, Linked Lists, Stacks, Queues, Searching, Sorting, Trees, Graphs and Hashing.

Each lesson includes: Definition, types, diagrams or examples, syntax and code where relevant, operations, applications, advantages, disadvantages, complexity and a Quick Check quiz with answers.
