Conditional Statements

Conditional statements help a program make decisions. They execute different blocks of code depending on whether a condition is true or false.

1. The if Statement

int mark = 85;if (mark >= 50) {
cout << "Passed";
}

Output:

Passed

2. The if-else Statement

int number = 7;if (number % 2 == 0) {
cout << "Even";
} else {
cout << "Odd";
}

Output:

Odd

3. The else-if Ladder

int mark = 85;if (mark >= 90) {
cout << "Grade A";
} else if (mark >= 75) {
cout << "Grade B";
} else if (mark >= 50) {
cout << "Grade C";
} else {
cout << "Failed";
}

Output:

Grade B

4. Nested if

An if statement inside another if statement is called a nested if.

int age = 20;
bool hasID = true;if (age >= 18) {
if (hasID) {
cout << "Entry allowed";
}
}

Output:

Entry allowed

Remember

  • Use == to compare two values.
  • Use = to assign a value.
  • Conditions are written inside parentheses.
  • Curly braces group the statements in a block.
