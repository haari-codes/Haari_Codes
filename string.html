09. Strings

📘 What is a String?

A string is a sequence of characters terminated by a special character called the null character '\0'.

In C, strings are stored using character arrays.

Example: 
char name[] = "Haari";

Here, the characters H, a, a, r, i and the terminating null character are stored in memory.

1️⃣ String Declaration

General syntax:

char string_name[size];

Example:

char name[20];
char city[30];

The array size determines how many characters can fit, including the terminating '\0'.

2️⃣ String Initialization

We can initialize a string while declaring it. 

char name[] = "Haari";

This is equivalent to:

char name[] = {'H', 'a', 'a', 'r', 'i', '\0'};
Remember:

A C string needs a terminating null character to mark the end of the string.

3️⃣ Displaying a String

We can use printf() with the %s format specifier to display a string. 

#include <stdio.h>

int main()
{
    char name[] = "Haari";

    printf("%s", name);

    return 0;
}
Output:

Haari

4️⃣ Reading a String

scanf() with %s can read a word from the user. It stops reading at whitespace. 

char name[30];

scanf("%29s", name);

printf("%s", name);

The width limit helps prevent input from exceeding the available array space.

Example input:

Haari

Output:

Haari

5️⃣ Important String Functions

Include <string.h> to use these standard string functions.

📏 strlen()

Returns the number of characters before '\0'. 

strlen("Hello");

Result: 5

📋 strcpy()

Copies a string into another character array.

char source[] = "Hello";
char destination[20];

strcpy(destination, source);

⚖️ strcmp()

Compares two strings.

strcmp("Apple", "Apple");

Result: 0, because both strings are equal. A nonzero result indicates a difference.

🔗 strcat()

Appends one string to the end of another.

char a[20] = "Hello ";
char b[] = "World";

strcat(a, b);

Result stored in a: Hello World

Important:

The destination array must have enough space for the combined string and its '\0' character.

💻 Complete Example Program

#include <stdio.h>
#include <string.h>

int main()
{
    char name[] = "Haari";

    printf("Name = %s\n", name);
    printf("Length = %zu", strlen(name));

    return 0;
}
Output: 
Name = Haari
Length = 5

📌 Important Points

  • Strings in C are stored as character arrays.
  • The null character '\0' marks the end of a string.
  • %s is commonly used to display strings.
  • strlen() finds the string length.
  • strcpy() copies a string.
  • strcmp() compares strings.
  • strcat() joins strings.
