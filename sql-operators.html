1. What are SQL Operators?

SQL operators are symbols or keywords used to perform comparisons, combine conditions, and filter records from a table.

Consider this sample table named Students:

id | name  | age | mark | city
1  | Anu   | 18  | 85   | Kochi
2  | Rahul | 19  | 72   | Calicut
3  | Meera | 18  | 91   | Kochi
4  | Arun  | 20  | 65   | Thrissur
5  | Diya  | 19  | 78   | NULL

2. Comparison Operators

These operators compare two values.

OperatorMeaningExample
=Equal toage = 18
<> or !=Not equal tocity <> 'Kochi'
>Greater thanmark > 80
<Less thanage < 20
>=Greater than or equal tomark >= 75
<=Less than or equal toage <= 19
SELECT * FROM Students
WHERE mark >= 80;

Result: Anu and Meera.

3. AND Operator

AND returns records only when all conditions are true.

SELECT * FROM Students
WHERE age = 18 AND mark > 85;

Result: Meera.

Both conditions must be true: age is 18 and mark is greater than 85.

4. OR Operator

OR returns records when at least one condition is true.

SELECT * FROM Students
WHERE city = 'Kochi' OR mark > 85;

Result: Anu and Meera.

Either condition can be true. A record satisfying both conditions is still returned only once.

5. NOT Operator

NOT reverses a condition.

SELECT * FROM Students
WHERE NOT city = 'Kochi';

This returns records whose city is not Kochi, excluding rows where city is NULL because that comparison is unknown.

You can also write:

SELECT * FROM Students
WHERE mark NOT BETWEEN 70 AND 85;

This selects marks outside the range 70 to 85.

6. BETWEEN Operator

BETWEEN checks whether a value falls within a range. Both endpoints are included.

SELECT * FROM Students
WHERE mark BETWEEN 70 AND 85;

Result: Anu (85), Rahul (72), and Diya (78).

It is equivalent to:

WHERE mark >= 70 AND mark <= 85
Remember: BETWEEN 70 AND 85 includes both 70 and 85.

7. IN Operator

IN checks whether a value matches any value in a list.

SELECT * FROM Students
WHERE city IN ('Kochi', 'Calicut');

Result: Anu, Rahul, and Meera.

It is a shorter alternative to:

WHERE city = 'Kochi'
   OR city = 'Calicut'

To exclude the listed values, use NOT IN.

8. LIKE Operator

LIKE searches for a pattern in text.

PatternMeaning
'A%'Starts with A
'%a'Ends with a
'%ee%'Contains ee
'A_u'A, followed by any one character, then u
'_n%'Second character is n

% represents zero or more characters. _ represents exactly one character.

SELECT * FROM Students
WHERE name LIKE 'A%';

Result: Anu and Arun.

SELECT * FROM Students
WHERE name LIKE '%ee%';

Result: Meera.

Pattern matching and case sensitivity can vary by database and collation.

9. IS NULL and IS NOT NULL

NULL means a value is missing or unknown. It is not the same as zero or an empty string.

SELECT * FROM Students
WHERE city IS NULL;

Result: Diya.

To find rows where city has a value:

SELECT * FROM Students
WHERE city IS NOT NULL;
Important: Never use city = NULL or city != NULL to test for NULL. Use IS NULL or IS NOT NULL.

10. Combining Conditions

You can combine operators to make more specific queries. Use parentheses to make your intention clear.

SELECT * FROM Students
WHERE (city = 'Kochi' OR city = 'Calicut')
  AND mark >= 80;

Result: Anu and Meera.

Without parentheses, SQL generally evaluates NOT before AND, and AND before OR. Parentheses help avoid confusion.

11. Quick Revision

  • AND: Every condition must be true.
  • OR: At least one condition must be true.
  • NOT: Reverses a condition.
  • BETWEEN: Checks an inclusive range.
  • IN: Matches any value in a list.
  • LIKE: Matches a text pattern.
  • IS NULL: Finds missing/unknown values.
  • IS NOT NULL: Finds values that are not NULL.
