Loops in C++

Loops repeat a block of code while a condition is true. They help avoid writing the same statements again and again.

1. for Loop

A for loop is useful when you know how many times you want to repeat an action.

for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}

Output:

1 2 3 4 5
  • int i = 1 initializes the loop variable.
  • i <= 5 is the condition.
  • i++ increases i by one after each iteration.

2. while Loop

A while loop checks the condition before each repetition.

int i = 1;while (i <= 3) {
cout << i << " ";
i++;
}

Output:

1 2 3

3. do-while Loop

A do-while loop executes its body at least once because the condition is checked afterward.

int i = 1;do {
cout << i << " ";
i++;
} while (i <= 3);

Output:

1 2 3

4. break and continue

break exits a loop. continue skips the current iteration and proceeds to the next one.

for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    cout << i << " ";
}

Output:

1 2 4 5

Remember

  • Make sure the loop condition can eventually become false.
  • For and while loops may execute zero times.
  • A do-while loop executes at least once.
