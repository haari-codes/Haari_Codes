Data Structures and Algorithms

Lesson 9: Graphs

1. What Is a Graph?

A graph is a non-linear data structure consisting of a set of vertices and a set of edges connecting them.

It is commonly represented as G = (V, E), where:

  • V: Set of vertices, also called nodes.
  • E: Set of edges connecting pairs of vertices.
A ----- B | | | | C ----- D

In this example, A, B, C and D are vertices. The lines connecting them are edges.

Real-life examples

  • Social networks: people are vertices, friendships are edges.
  • Maps: places are vertices, roads are edges.
  • Computer networks: computers are vertices, connections are edges.
  • Airline routes: airports are vertices, flights are edges.

2. Graph Terminology

  • Vertex: An individual node in a graph.
  • Edge: A connection between two vertices.
  • Adjacent vertices: Vertices directly connected by an edge.
  • Degree: In an undirected graph, the number of edges incident to a vertex. A self-loop contributes two to the degree.
  • Path: A sequence of vertices connected by edges.
  • Cycle: A path that returns to its starting vertex, following the graph's edges.
  • Connected graph: An undirected graph in which every vertex can reach every other vertex.
  • Weighted graph: A graph whose edges have values such as distance, cost or time.
  • Component: A maximal connected part of an undirected graph.

Unlike a tree, a graph may contain cycles and may have multiple separate components.

3. Types of Graphs

A. Undirected Graph

Edges have no direction. If A is connected to B, the connection can be followed both ways.

A ----- B \ / \ / C

B. Directed Graph

Each edge has a direction, often shown using an arrow. A connection from A to B does not automatically mean B connects to A.

A ----> B ----> C

C. Weighted Graph

Edges carry weights such as distance or cost.

A --5-- B \ / 2 3 \ / C

D. Unweighted Graph

Edges are treated as connections without numerical weights.

E. Connected and Disconnected Graphs

A connected undirected graph has a path between every pair of vertices. A disconnected graph has at least two vertices that cannot reach each other.

F. Cyclic and Acyclic Graphs

A cyclic graph contains a cycle. An acyclic graph does not. A connected, undirected, acyclic graph is called a tree.

4. Graph Representation

Graphs can be stored in different ways. Two common methods are the adjacency matrix and adjacency list.

A. Adjacency Matrix

An adjacency matrix is a two-dimensional array. For an unweighted graph, matrix[i][j] = 1 means an edge connects vertex i to vertex j; otherwise it is 0.

Consider an undirected graph with edges A-B, A-C and B-C.

ABC
A011
B101
C110

For an undirected graph without special edge cases, the matrix is symmetric: matrix[i][j] = matrix[j][i].

C++ Example

#include <iostream>
using namespace std;

int main() {
    int matrix[3][3] = {
        {0, 1, 1},
        {1, 0, 1},
        {1, 1, 0}
    };

    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++)
            cout << matrix[i][j] << " ";
        cout << endl;
    }

    return 0;
}

B. Adjacency List

An adjacency list stores the neighbours of each vertex. It is often more memory-efficient for sparse graphs, which have relatively few edges.

For the same graph:

A: B, C
B: A, C
C: A, B

C++ Example

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<vector<int>> adj(3);

    adj[0].push_back(1);
    adj[0].push_back(2);

    adj[1].push_back(0);
    adj[1].push_back(2);

    adj[2].push_back(0);
    adj[2].push_back(1);

    for (int i = 0; i < 3; i++) {
        cout << i << ": ";
        for (int v : adj[i])
            cout << v << " ";
        cout << endl;
    }

    return 0;
}

Output:

0: 1 2
1: 0 2
2: 0 1

In this program, vertices are numbered 0, 1 and 2 instead of A, B and C. The connections are the same.

5. Breadth-First Search (BFS)

Definition

BFS is a graph traversal algorithm that visits vertices level by level, exploring nearby vertices before moving farther away.

BFS commonly uses a queue to maintain the order of vertices waiting to be explored.

Algorithm

  1. Mark the starting vertex as visited.
  2. Insert it into a queue.
  3. Remove the front vertex and process it.
  4. Add each unvisited neighbour to the queue and mark it visited.
  5. Repeat until the queue is empty.

C++ Program

This program uses an undirected graph with vertices numbered 0 to 4.

#include <iostream>
#include <vector>
#include <queue>
using namespace std;

int main() {
    int n = 5;
    vector<vector<int>> adj(n);

    adj[0] = {1, 2};
    adj[1] = {0, 3};
    adj[2] = {0, 4};
    adj[3] = {1};
    adj[4] = {2};

    vector<bool> visited(n, false);
    queue<int> q;

    int start = 0;
    visited[start] = true;
    q.push(start);

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        cout << u << " ";

        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                q.push(v);
            }
        }
    }

    return 0;
}

Output: 0 1 2 3 4

The order can differ if neighbours are stored in a different order.

Applications

  • Finding the shortest path in an unweighted graph.
  • Finding all vertices reachable from a starting point.
  • Exploring a network level by level.
  • Finding connected components when repeated from unvisited vertices.

6. Depth-First Search (DFS)

Definition

DFS explores as far as possible along one path before backtracking to explore another path.

DFS can be implemented using recursion or an explicit stack.

Algorithm using recursion

  1. Start from a vertex.
  2. Mark it as visited and process it.
  3. Visit each unvisited neighbour recursively.
  4. Backtrack when no unvisited neighbours remain.

C++ Program

#include <iostream>
#include <vector>
using namespace std;

void dfs(int u, vector<vector<int>>& adj,
         vector<bool>& visited) {
    visited[u] = true;
    cout << u << " ";

    for (int v : adj[u]) {
        if (!visited[v])
            dfs(v, adj, visited);
    }
}

int main() {
    int n = 5;
    vector<vector<int>> adj(n);

    adj[0] = {1, 2};
    adj[1] = {0, 3};
    adj[2] = {0, 4};
    adj[3] = {1};
    adj[4] = {2};

    vector<bool> visited(n, false);

    dfs(0, adj, visited);

    return 0;
}

Output: 0 1 3 2 4

The output depends on the order of neighbours in the adjacency list.

Applications

  • Detecting cycles in graphs.
  • Exploring mazes and paths.
  • Finding connected components.
  • Topological sorting in directed acyclic graphs, using an appropriate DFS-based method.

7. BFS vs DFS

FeatureBFSDFS
Full formBreadth-First SearchDepth-First Search
ExplorationLevel by levelDeep along a path, then backtracks
Main structureQueueStack or recursion
Shortest pathFinds shortest paths in unweighted graphsDoes not generally guarantee shortest paths
Time with adjacency listO(V + E)O(V + E)
Extra spaceO(V)O(V), including visited and traversal storage

V is the number of vertices and E is the number of edges. These complexities assume an adjacency-list representation and a traversal that accounts for all relevant vertices and edges.

8. Advantages and Disadvantages

Advantages

  • Represents complex relationships naturally.
  • Supports route planning and network analysis.
  • Can model directed, weighted and interconnected data.
  • BFS and DFS efficiently explore reachable vertices.

Disadvantages

  • Large graphs can require substantial memory.
  • Choosing a suitable representation can be important.
  • Some graph algorithms are difficult to implement correctly.
  • Cycles require visited tracking in many traversal algorithms to prevent repeated exploration.
