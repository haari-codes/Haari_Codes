HTML Links & Images

CS Companion | HTML Lesson 04

1. What Is a Hyperlink?

A hyperlink connects one webpage or resource to another. In HTML, we use the anchor tag <a>. 

<a href="https://www.wikipedia.org">
  Visit Wikipedia
</a>

Here:

  • <a> is the anchor tag.
  • href specifies the destination.
  • The text between the tags becomes clickable.

Example: Visit Wikipedia

2. Types of Links

External Link

Opens a page on another website.

<a href="https://www.example.com">
  Visit Website
</a>

Internal Link

Connects to another page in the same project.

<a href="html-tags.html">
  Learn HTML Tags
</a>

The destination filename must match the actual file.

Email Link

<a href="mailto:hello@example.com">
  Send Email
</a>

Open a Link in a New Tab

<a href="https://www.example.com"
   target="_blank"
   rel="noopener noreferrer">
  Open Website
</a>

target="_blank" opens the destination in a new tab or window.

3. What Is an HTML Image?

Images make webpages more informative and attractive. HTML uses the <img> tag to display an image. 

<img src="flower.jpg"
     alt="A pink flower"
     width="300">

Important attributes:

  • src: location or path of the image.
  • alt: text describing the image if it cannot load; also useful for screen readers.
  • width: specifies the image width.
  • height: specifies the image height.

The <img> tag is a void element, so it does not need a closing tag.

4. Understanding Image Paths

Same Folder

index.html
flower.jpg
<img src="flower.jpg" alt="Flower">

Image Inside a Folder

index.html
images/
  flower.jpg
<img src="images/flower.jpg" alt="Flower">

Parent Folder

<img src="../flower.jpg" alt="Flower">

../ means move up one folder level.

Remember: On GitHub Pages, filenames and folder names must match, including uppercase and lowercase letters.

5. Clickable Image

An image can also work as a link by placing the image inside an anchor tag.

<a href="https://www.wikipedia.org">
  <img src="flower.jpg"
       alt="Open Wikipedia">
</a>

Clicking the image opens the linked destination.
