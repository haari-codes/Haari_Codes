C++ Functions

A function is a block of code that performs a specific task. Functions help us reuse code and make programs easier to understand.

1. Creating a Function

#include <iostream>
using namespace std;void greet() {
cout << "Hello, student!";
}

int main() {
greet();
return 0;
}

Output:

Hello, student!

The function runs when we call it using greet();.

2. Function Parameters

Parameters allow us to pass information to a function.

void greet(string name) {
    cout << "Hello, " << name;
}// Function call:
greet("Haari");

Output:

Hello, Haari

3. Returning a Value

A function can return a calculated value using the return keyword.

int add(int a, int b) {
    return a + b;
}int main() {
cout << add(5, 3);
return 0;
}

Output:

8

4. The void Keyword

void means that a function does not return a value.

void display() {
    cout << "Welcome!";
}

5. Function Declaration

A declaration tells the compiler about a function before it is used.

int square(int);int main() {
cout << square(4);
return 0;
}

int square(int n) {
return n * n;
}

Output:

16

Remember

  • Functions help reuse code.
  • Parameters receive information.
  • return sends a value back.
  • void means no return value.
