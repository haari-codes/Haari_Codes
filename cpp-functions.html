C++ Functions

A function is a block of code that performs a specific task. We can call a function whenever we need it, which helps us reuse code and keep programs organised.

1. Why Do We Use Functions?

  • To reuse code.
  • To reduce repetition.
  • To make programs easier to understand.
  • To divide a large program into smaller parts.

2. Creating and Calling a Function

#include <iostream>
using namespace std;void greet() {
cout << "Hello, student!";
}

int main() {
greet();
return 0;
}

Output:

Hello, student!

Here, greet() is the function name. The function runs when we call it using greet();.

3. Function Parameters

Parameters allow us to pass information into a function.

#include <iostream>
using namespace std;void greet(string name) {
cout << "Hello, " << name;
}

int main() {
greet("Haari");
return 0;
}

Output:

Hello, Haari

The value "Haari" is passed to the parameter name.

4. Return Values

A function can calculate a value and return it to the place where it was called.

#include <iostream>
using namespace std;int add(int a, int b) {
return a + b;
}

int main() {
int result = add(5, 3);
cout << result;
return 0;
}

Output:

8

The function add() receives two integers and returns their sum. Since the return type is int, it returns an integer value.

5. The void Keyword

The void return type means the function does not return a value.

void display() {
    cout << "Welcome!";
}

6. Function Declaration and Definition

A function declaration, also called a prototype, tells the compiler about a function before it is used. The definition contains the actual code.

#include <iostream>
using namespace std;int square(int);

int main() {
cout << square(4);
return 0;
}

int square(int n) {
return n * n;
}

Output:

16

int square(int); is the declaration. The later block containing return n * n; is the definition.

Quick Revision

  • void: function does not return a value.
  • return: sends a value back to the caller.
  • Parameters: receive values passed to a function.
  • Function call: executes the function.
