SQL Functions

Make SQL queries more powerful!

1. What are SQL Functions?

SQL functions are built-in operations that process values and return a result.

For example, a function can convert text to uppercase, calculate an average, count records, or extract part of a string.

SELECT UPPER('haari_codes');

Result: HAARI_CODES

Types of SQL Functions

  • String functions: Work with text.
  • Numeric functions: Perform mathematical operations.
  • Date functions: Work with dates and times.
  • Aggregate functions: Calculate a result from multiple rows.

2. String Functions

String functions manipulate text values.

UPPER()

Converts text to uppercase.

SELECT UPPER('hello');

Result: HELLO

LOWER()

Converts text to lowercase.

SELECT LOWER('SQL COURSE');

Result: sql course

LENGTH()

Returns the length of a string in bytes in MySQL. For ordinary English text, this often equals the character count.

SELECT LENGTH('HAARI');

Result: 5

CHAR_LENGTH()

Returns the number of characters in MySQL.

SELECT CHAR_LENGTH('HAARI');

Result: 5

CONCAT()

Combines strings.

SELECT CONCAT('Haari', '_Codes');

Result: Haari_Codes

SUBSTRING()

Extracts part of a string. In MySQL, positions start at 1.

SELECT SUBSTRING('DATABASE', 1, 4);

Result: DATA

TRIM()

Removes leading and trailing spaces.

SELECT TRIM('  SQL  ');

Result: SQL

3. Numeric Functions

Numeric functions perform calculations on numbers.

FunctionPurposeExampleResult
ABS()Absolute valueABS(-8)8
ROUND()Rounds a numberROUND(4.567, 2)4.57
CEIL()Rounds upwardCEIL(4.2)5
FLOOR()Rounds downwardFLOOR(4.8)4
MOD()Returns remainderMOD(10, 3)1

Example:

SELECT ABS(-25) AS positive_value,
       ROUND(12.456, 2) AS rounded_value;

Result: positive_value = 25 and rounded_value = 12.46.

4. Aggregate Functions

Aggregate functions calculate one result from a set of rows.

Suppose we have a table called Students:

name  | mark
Anu   | 85
Rahul | 72
Meera | 91
Arun  | 65
Diya  | 78

COUNT()

Counts rows or non-NULL values, depending on the expression.

SELECT COUNT(*) FROM Students;

Result: 5

COUNT(*) counts all rows, while COUNT(mark) counts rows where mark is not NULL.

SUM()

Calculates the total of non-NULL values.

SELECT SUM(mark) FROM Students;

Result: 391

AVG()

Calculates the average of non-NULL values.

SELECT AVG(mark) FROM Students;

Result: 78.2

MAX()

Returns the highest value.

SELECT MAX(mark) FROM Students;

Result: 91

MIN()

Returns the lowest value.

SELECT MIN(mark) FROM Students;

Result: 65

Aggregate functions generally ignore NULL values, except COUNT(*), which counts rows even if some columns contain NULL.

5. Using Functions with WHERE

You can use functions inside a query to filter records.

SELECT name, mark
FROM Students
WHERE mark >= 80;

This returns students with marks of 80 or above.

You can also use a string function in a condition:

SELECT *
FROM Students
WHERE UPPER(name) = 'ANU';

This finds the row whose name matches ANU after conversion to uppercase. Applying functions to columns in conditions can sometimes affect index usage.

6. Date Functions

Date functions vary between database systems. These examples use MySQL.

CURDATE()

Returns the current date.

SELECT CURDATE();

NOW()

Returns the current date and time.

SELECT NOW();

YEAR()

Extracts the year from a date.

SELECT YEAR('2026-10-18');

Result: 2026

MONTH()

Extracts the month number.

SELECT MONTH('2026-10-18');

Result: 10

The exact date and time returned by CURDATE() and NOW() depend on the database server's current date, time, and time-zone settings.

7. Aliases with AS

An alias gives a column or calculated result a temporary display name.

SELECT AVG(mark) AS average_mark,
       MAX(mark) AS highest_mark
FROM Students;

The output columns will be named average_mark and highest_mark.

AS changes the output label. It does not rename the original table column.

8. Common Mistakes

  • Forgetting parentheses after a function name.
  • Using COUNT(column) when you intend to count every row. Use COUNT(*) for all rows.
  • Assuming AVG() treats NULL as zero. It normally ignores NULL values.
  • Confusing LENGTH() with character count. In MySQL, use CHAR_LENGTH() for characters.
  • Assuming every database uses the same date-function syntax. Check which database system you are using.

9. Quick Revision

  • UPPER() and LOWER(): Change letter case.
  • CONCAT(): Joins strings.
  • SUBSTRING(): Extracts part of a string.
  • ROUND(): Rounds a number.
  • COUNT(): Counts rows or non-NULL values.
  • SUM(): Calculates a total.
  • AVG(): Calculates an average.
  • MAX() and MIN(): Find the highest and lowest values.
  • CURDATE() and NOW(): Return current date and date-time in MySQL.
