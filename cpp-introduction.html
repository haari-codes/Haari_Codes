Introduction to C++

C++ is a general-purpose programming language used to develop applications, games and system software. It supports procedural and object-oriented programming.

First C++ Program

#include <iostream>
using namespace std;int main() {
cout << "Hello World!";
return 0;
}

Understanding the Code

  • #include <iostream> enables input and output operations.
  • int main() is the main function where program execution begins.
  • cout displays output on the screen.
  • return 0; indicates successful program completion.

Expected Output

Hello World!
