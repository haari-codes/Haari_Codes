🔎 Lesson 07:GROUPBY and HAVING

1. What is GROUP BY?

GROUP BY groups rows that have the same value in one or more columns. It is commonly used with aggregate functions such as COUNT(), SUM(), AVG(), MAX(), and MIN().

Consider this table named Employees:

namedepartmentsalary
AnuIT30000
RahulHR25000
MeeraIT40000
ArunHR28000
DiyaSales22000

To calculate the total salary for each department:

SELECT department, SUM(salary) AS total_salary
FROM Employees
GROUP BY department;

Expected result:

departmenttotal_salary
HR53000
IT70000
Sales22000

Rows are grouped by department, and SUM() calculates each group's total.

2. GROUP BY with COUNT()

Count how many employees work in each department.

SELECT department, COUNT(*) AS employee_count
FROM Employees
GROUP BY department;

Expected result:

departmentemployee_count
HR2
IT2
Sales1

COUNT(*) counts the rows in each group.

3. GROUP BY with AVG(), MAX(), and MIN()

Find the average salary in each department:

SELECT department, AVG(salary) AS average_salary
FROM Employees
GROUP BY department;

Find the highest salary in each department:

SELECT department, MAX(salary) AS highest_salary
FROM Employees
GROUP BY department;

Find the lowest salary in each department:

SELECT department, MIN(salary) AS lowest_salary
FROM Employees
GROUP BY department;
Aggregate functions generally ignore NULL values. COUNT(*) counts all rows in a group, while COUNT(column) counts only non-NULL values in that column.

4. GROUP BY with Multiple Columns

You can group by more than one column. Each distinct combination forms a separate group.

SELECT department, job_title, COUNT(*) AS total
FROM Employees
GROUP BY department, job_title;

This example assumes the Employees table has a job_title column. It counts employees for each department and job-title combination.

For example, IT + Developer and IT + Tester would be two separate groups.

5. What is HAVING?

HAVING filters groups after they have been formed. It is especially useful for conditions involving aggregate functions.

Example: show only departments whose total salary is greater than 30000.

SELECT department, SUM(salary) AS total_salary
FROM Employees
GROUP BY department
HAVING SUM(salary) > 30000;

Expected result: HR and IT. Sales is excluded because its total is 22000.

6. WHERE vs HAVING

WHEREHAVING
Filters individual rows.Filters groups.
Applied before grouping.Applied after grouping.
Usually filters regular column values.Often filters aggregate results.

Example: first select employees earning at least 25000, then group them by department, and finally show departments with at least two qualifying employees.

SELECT department, COUNT(*) AS employee_count
FROM Employees
WHERE salary >= 25000
GROUP BY department
HAVING COUNT(*) >= 2;

Only HR qualifies: Rahul and Arun both earn at least 25000. IT also qualifies: Anu and Meera both earn at least 25000.

7. GROUP BY with ORDER BY

Use ORDER BY to sort grouped results.

SELECT department, SUM(salary) AS total_salary
FROM Employees
GROUP BY department
ORDER BY total_salary DESC;

This displays departments from the highest total salary to the lowest.

  • ASC: ascending order, generally the default.
  • DESC: descending order.

8. SQL Query Execution Order

A useful simplified logical order for these clauses is:

SELECT
FROM
WHERE
GROUP BY
HAVING
ORDER BY

The database logically identifies the source rows, filters rows with WHERE, groups them, filters groups with HAVING, then sorts the result with ORDER BY and returns the selected columns.

This is a simplified logical processing order, not necessarily the physical order in which the database executes operations.

9. Common Mistakes

  • Using WHERE SUM(salary) > 30000. Use HAVING for a condition on the aggregate result.
  • Selecting an ordinary column that is neither grouped nor aggregated. This can cause an error or produce unreliable results, depending on the database settings.
  • Forgetting the GROUP BY clause when trying to calculate separate results for each category.
  • Confusing COUNT(*), which counts rows, with COUNT(column), which ignores NULL in that column.

10. Quick Revision

  • GROUP BY: Groups rows with matching values.
  • COUNT(): Counts rows or non-NULL values.
  • SUM(): Calculates a total.
  • AVG(): Calculates an average.
  • MAX() / MIN(): Finds the highest / lowest value.
  • WHERE: Filters rows before grouping.
  • HAVING: Filters groups after grouping.
  • ORDER BY: Sorts the resulting rows.
