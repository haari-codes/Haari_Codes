🗄️ Lesson 01: SQL Introduction

1. What is SQL?

SQL stands for Structured Query Language.

It is a language used to communicate with relational database management systems (RDBMS). We use SQL to create tables, store data, retrieve information, update records and delete records.

Example

Imagine a college database containing student names, roll numbers and marks. SQL helps us find a particular student's marks without searching every record manually.

SELECT name, mark
FROM Students;

This query retrieves the name and mark columns from the Students table.

2. What is a Database?

A database is an organized collection of data that can be stored, accessed and managed efficiently.

Examples of databases

  • College student records
  • Bank account information
  • Hospital patient records
  • Online shopping products and orders
  • Railway reservation information
Remember: A database organizes information so that it can be accessed and managed efficiently.

3. What is a DBMS?

DBMS stands for Database Management System.

It is software used to create, store, organize and manage databases.

Examples

  • MySQL
  • PostgreSQL
  • Oracle Database
  • Microsoft SQL Server
  • SQLite

A relational DBMS stores related data in tables and can use SQL to manage that data.

SQL vs DBMS

SQL: The language used to communicate with a database.

DBMS: The software that manages the database.

4. What is a Table?

A table stores data in rows and columns.

Example: Students

id name mark
1 Anu 90
2 Akhil 85
3 Meera 95
  • Table: Students
  • Columns: id, name, mark
  • Rows: Individual student records
  • Field: An individual data value within a record

5. Types of SQL Commands

DDL: Data Definition Language

Used to define or change database structures.

CREATE TABLE Students (
    id INT,
    name VARCHAR(50)
);

Common commands: CREATE, ALTER, DROP, TRUNCATE.

DML: Data Manipulation Language

Used to insert, modify and remove table records.

INSERT INTO Students
VALUES (1, 'Anu');

UPDATE Students
SET name = 'Meera'
WHERE id = 1;

DELETE FROM Students
WHERE id = 1;

Common commands: INSERT, UPDATE, DELETE.

DQL: Data Query Language

Used to retrieve data.

SELECT * FROM Students;

DCL: Data Control Language

Used to manage database access permissions.

Common commands: GRANT and REVOKE.

TCL: Transaction Control Language

Used to manage database transactions.

Common commands: COMMIT, ROLLBACK and SAVEPOINT.

Command classifications can vary slightly across textbooks and database systems. For this course, we will study these common categories.

6. Common SQL Data Types

  • INT: Whole numbers, such as 10 or 250.
  • VARCHAR(n): Variable-length text up to a specified maximum length.
  • CHAR(n): Fixed-length character strings.
  • DATE: Date values.
  • DECIMAL(p,s): Exact decimal numbers, useful for monetary values.
  • BOOLEAN: True/false values in systems that support it directly. Other systems may represent these differently.

Example

CREATE TABLE Students (
    id INT,
    name VARCHAR(50),
    mark DECIMAL(5,2),
    admission_date DATE
);

This creates a table structure. It does not automatically add any student records.

7. Create a Table and Retrieve Data

Step 1: Create the table

CREATE TABLE Students (
    id INT,
    name VARCHAR(50),
    mark INT
);

Step 2: Insert a record

INSERT INTO Students
VALUES (1, 'Anu', 90);

Step 3: Retrieve the record

SELECT * FROM Students;

Expected output

id name mark
1 Anu 90

The output assumes the table was empty before the INSERT statement and all three commands ran successfully.

8. Advantages of SQL

  • Retrieves large amounts of data efficiently.
  • Can insert, update and delete records.
  • Supports filtering, sorting and grouping.
  • Works with many relational database systems.
  • Can help control access and maintain data integrity.

9. Applications of SQL

  • Banking and financial systems
  • College and school management
  • Railway and airline reservations
  • E-commerce websites
  • Hospital management systems
  • Business reporting and data analysis

📌 Lesson Summary

  • SQL means Structured Query Language.
  • A database stores organized information.
  • A DBMS manages databases.
  • Tables contain rows and columns.
  • SQL commands are grouped into common categories such as DDL, DML, DQL, DCL and TCL.
  • SELECT retrieves data, INSERT adds records, and UPDATE changes records.
