HTML Tags & Elements

HTML tags define the structure and meaning of content on a webpage. Tags are written inside angle brackets, such as <p>.

An HTML element commonly contains an opening tag, content and a closing tag.

<p>Welcome to Haari Codes!</p>

1. Opening and Closing Tags

  • Opening tag: <p>
  • Content: Welcome!
  • Closing tag: </p>

The closing tag contains a forward slash before the tag name.

<h1>My Website</h1>
<p>This is a paragraph.</p>

2. Heading Tags

HTML provides six heading levels, from <h1> to <h6>.

<h1>Main Heading</h1>
<h2>Section Heading</h2>
<h3>Subsection</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

Main Heading

Section Heading

Subsection

Heading 5
Heading 6

Use headings in a logical order to make your content easier to navigate.

3. Paragraph and Line Break

<p>This is paragraph one.</p>
<p>This is paragraph two.</p>
Hello<br>World

<p> creates a paragraph. <br> inserts a line break without creating a new paragraph.

4. Text Formatting Tags

<strong>Important text</strong>
<em>Emphasized text</em>
<b>Bold appearance</b>
<i>Italic appearance</i>
<u>Underlined text</u>
<mark>Highlighted text</mark>
<del>Deleted text</del>
<sub>Subscript</sub>
<sup>Superscript</sup>
Important text
Emphasized text
Highlighted text
H2O and x2

<strong> and <em> convey meaning as well as presentation. Use them when that meaning is intended.

5. Container Tags

Div element

<div> is a generic block-level container used to group content.

<div>
  <h2>About Me</h2>
  <p>I am learning HTML.</p>
</div>

Span element

<span> is a generic inline container, often used to style part of a sentence.

<p>Learn <span>HTML</span> today!</p>

6. Empty or Void Elements

Some HTML elements do not wrap content and do not require closing tags.

<br>
<hr>
<img src="flower.jpg" alt="Flower">
<input type="text">
  • <br>: line break
  • <hr>: thematic break
  • <img>: image
  • <input>: form input

7. Advantages of Using HTML Elements

  • Organizes webpage content.
  • Helps browsers understand content structure.
  • Semantic elements can improve accessibility.
  • Works with CSS and JavaScript to build websites.

Common Mistakes

  • Forgetting a closing tag when one is required.
  • Using headings only to make text bigger.
  • Incorrectly nesting elements.
  • Using obsolete tags instead of modern semantic HTML.
