05. Conditional Statements

Conditional statements are used to make decisions in a C program.

They allow a program to execute different blocks of code depending on a condition.

🤔 What is a Condition?

A condition is an expression that can be either true or false.

age >= 18
If the condition is true, one block of code can be executed.

If the condition is false, another block can be executed.

🔹 if Statement

The if statement executes a block of code only when the condition is true.

if (age >= 18) {     printf("You are an adult"); }

🔹 if-else Statement

The if-else statement is used when there are two possible outcomes.

if (age >= 18) {     printf("Adult"); } else {     printf("Minor"); }

🔹 else-if Statement

The else-if statement is used when there are multiple conditions to check.

if (mark >= 90) {     printf("A Grade"); } else if (mark >= 75) {     printf("B Grade"); } else {     printf("C Grade"); }

🔹 switch Statement

The switch statement is useful when we need to choose between multiple fixed options.

switch(choice) {     case 1:         printf("One");         break;     case 2:         printf("Two");         break;     default:         printf("Invalid choice"); }

💻 Example Program

#include <stdio.h> int main() {     int number;     printf("Enter a number: ");     scanf("%d", &number);     if (number > 0)     {         printf("Positive number");     }     else if (number < 0)     {         printf("Negative number");     }     else     {         printf("Zero");     }     return 0; }
