HTML Tables

CS Companion | HTML Lesson 06

1. What Is an HTML Table?

An HTML table organises information into rows and columns. It is useful for displaying student marks, timetables, price lists and other structured data.

<table>
  <tr>
    <th>Name</th>
    <th>Mark</th>
  </tr>
  <tr>
    <td>Anu</td>
    <td>95</td>
  </tr>
</table>
NameMark
Anu95

2. Important Table Tags

  • <table>: creates the table.
  • <tr>: creates a table row.
  • <th>: creates a header cell.
  • <td>: creates a normal data cell.
  • <caption>: adds a table title.
  • <thead>: groups the header rows.
  • <tbody>: groups the main data rows.
  • <tfoot>: groups footer or summary rows.

Example using table sections:

<table>
  <caption>Student Marks</caption>
  <thead>
    <tr>
      <th>Name</th>
      <th>Mark</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Anu</td>
      <td>95</td>
    </tr>
  </tbody>
</table>

3. Adding Rows and Columns

Each <tr> creates a row. Inside it, use <th> or <td> to create cells.

<table>
  <tr>
    <th>Subject</th>
    <th>Mark</th>
  </tr>
  <tr>
    <td>Computer Science</td>
    <td>90</td>
  </tr>
  <tr>
    <td>English</td>
    <td>88</td>
  </tr>
</table>
SubjectMark
Computer Science90
English88

4. The colspan Attribute

colspan makes a cell span across multiple columns.

<table>
  <tr>
    <th colspan="2">Student Details</th>
  </tr>
  <tr>
    <td>Anu</td>
    <td>95</td>
  </tr>
</table>
Student Details
Anu95

Here, the heading occupies two columns.

5. The rowspan Attribute

rowspan makes a cell span across multiple rows.

<table>
  <tr>
    <th rowspan="2">CS</th>
    <td>HTML</td>
  </tr>
  <tr>
    <td>CSS</td>
  </tr>
</table>
CSHTML
CSS

The CS cell extends across two rows.

6. Styling Tables with CSS

CSS can add borders, spacing, colours and alignment to tables.

table {
  width: 100%;
  border-collapse: collapse;
}

th, td {
  border: 1px solid black;
  padding: 10px;
}

th {
  background-color: lavender;
}
  • border-collapse: collapse combines adjacent borders.
  • padding adds space inside cells.
  • text-align controls horizontal text alignment.
  • background-color changes the background colour.
